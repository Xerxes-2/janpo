# ADR-0006：强 AI 基线走浏览器内 WASM，不开后端

**日期**：2026-08-19
**状态**：已接受（推翻 spec 三处）

## 背景

spec 起草时对「强 AI 基线」只有一条路可走，于是写下了三句话：

- 接入方式：「**轻量容器承载 Mortal，经 WebSocket 讲 mjai** 与前端牌桌通信」
- Out of Scope：「**Mortal 的 WASM 化/浏览器内推理**」
- story 37：「我想在 **Mortal 后端不可用**时仍能正常开没有 Mortal 的桌」

这三句的共同前提是**强 AI 必须在浏览器外跑**——因为当时手上的候选是 Mortal，
而 Mortal 的推理栈是 PyTorch，进浏览器不现实。

M3 起草时前提变了：主人拿到了 `shinkuan/Akagi` 的授权，且**允许连权重一起公开分发到 GitHub Pages**。
Akagi v3 是 Rust + Tauri 单二进制，README 自称内置「a pure-Rust neural net embedded in the binary」。
纯 Rust 推理 ⇒ WASM 在理论上可行。**但当时那只是读 README 得来的印象**，
所以 M3 起草时定了规矩：**翻案的 ADR 等票 91 查实后再写——先有事实再写案，不倒过来。**

票 91 现在把事实拿回来了（`run/reports/91-wasm-baseline-probe.md`，20 个验收框全勾）。

## 决定

**强 AI 基线编译为 `wasm32-unknown-unknown`、权重内嵌、在浏览器内推理，不开任何后端。**

连带三条：

1. **术语改为通名「强 AI 基线」**（主人第九次术语授权，2026-08-19）。
   `CONTEXT.md` 与 spec 里那一排「Mortal 基线」是**事实错误**——票 91 查实我们要接的那个网络
   **不是 Mortal**：`native_bot/Cargo.toml` 自称 `libriichi-free`、`derives from no copyleft source`，
   上游 `NOTICE` 里的第三方只有 mahjong-helper（MIT）与 riichienv-core（Apache-2.0），
   且那两条都在 Akagi 本体、`native_bot/` 一行未引。
   **仍在说 Mortal 本身的地方不改**（spec 里两处生态陈述、`docs/research/shanten-vs-libriichi.md` 全篇）。
2. **spec 的 Out of Scope 删掉「WASM 化/浏览器内推理」那一条**，接入方式那一节整节重写。
3. **story 37 的语义翻译**：「后端不可用时降级」在无后端形态下 = 「**资产拉不动 / 跑不起来时降级**」。
   它仍是可选依赖而非单点，闸门形状不变。

## 核心论据：量出来的数，不是「理论可行」

| 量 | 实测 | 测量条件 |
|---|---|---|
| 产物体积 | **6.0 MB**（其中 **4.8 MB 是内嵌权重**，代码约 1.2 MB） | `--release`, `strip=true`, `lto=true`；权重 `include_bytes!` |
| 单手推理 | **中位 0.368 ms / p95 ≤ 0.644 ms** | **n = 17,260**：111 份真实天凤牌谱全场重放，座位 0 被问到的每一手（每场取中位，再取 111 个中位的中位） |
| 立直手 | **≈ 0.7 ms**（两次前向） | mjai 的 `reach` 必须同时说出宣言牌 ⇒ top1 是 Riichi 时再跑 `predict_reach_discard` |
| 一整场半庄 | **89 ms**（181 个决策点、1,259 行事件） | node V8 |
| 常驻内存 | **11.0 MiB，不漏** | 反复推理后回落 |
| wasm 税 | **2.4×**（0.663 ms vs 原生 0.281 ms） | 同一局面、同一份 `native_bot` 源码；未开 `simd128` |

**「一个强 AI 打完整场半庄」比「一次 LLM API 调用」还快两个数量级**（89 ms vs 1.7 s 单手）。
延迟这一项因此完全不构成约束，**唯一的真实成本是那 6 MB 的下载**——所以后续票的边界全压在懒加载上。

## 次要论据

1. **无后端与 ADR-0003 同向。** ADR-0003 定了「不做实时观战，主持人驱动对局」，
   平台形态是**一个静态站点 + 用户自带 key**。开一个容器就要有人运维它、有人付它的钱、
   有人在它挂掉时被叫起来——那与「分享给普通人围观」是矛盾的。
   spec 立项动机里那句「现有工具（Mortal 本地部署）安装门槛极高」，
   如果我们自己也要求装容器，就等于把自己批评的东西复制了一遍。
2. **接缝不变，所以这不是架构变更。** 强 AI 对内仍只讲 mjai（票 91 实测：输入是 mjai 事件流，
   输出差一层薄翻译）。ADR-0005 的跨界规矩照旧：**TS/WASM 侧永不构造 `Action`，只回 id**。
3. **许可干净且义务清楚。** Apache-2.0 §4 的四项义务已逐条落地成上线清单
   （`probe/akagi-wasm/NOTICE-upstream.md`）：站点放 `LICENSE-akagi.txt` 与 `NOTICE-akagi`，
   页脚加一条第三方组件声明。我们**一行上游源码都没改**（只从外面链接），§4(b)(c) 自动满足。

## 被否决的选项

- **轻后端容器 + WebSocket（spec 原方案）**：见次要论据 1。它今天唯一的优势是「不必下 6 MB」,
  而 6 MB 是**一次性、可缓存、且只在选了那一席时才付**的成本。
- **权重放 CDN、代码放 Pages**：省不了字节，只多一个第三方依赖与一个 CORS 面。
  真到体积成问题时该做的是量化权重（f16/int8），不是换个地方放。
- **开 `simd128` 把 wasm 税从 2.4× 收窄**：0.37 ms 已远低于任何人能感知的阈值，
  换来的是要盯 target feature 的兼容面。**不做，理由是收益为零而不是成本高。**
- **等上游确认语料出处再上线**：见「后果」第 1 条——主人已裁定照原样分发。

## 后续票要遵守的边界

1. **懒加载是硬约束**：首页与普通对局**一个字节都不许拉**；只有选了那一席才拉，拉的时候页面要说话。
   闸门形状：不选它的那些趟断言网络请求计数为 0。
2. **降级不是 try/catch**：拉不动 / 跑不起来时页面**明说原因**，且**其余席照常打完一局**。
   它是可选依赖，不是单点（story 37）。
3. **排预算按「立直手 0.7 ms」**，不是按平均 0.37 ms。
4. **上线要带许可**：`LICENSE-akagi.txt` + `NOTICE-akagi` + 页脚第三方声明 + 来源 commit `394b3290`。
5. **术语用通名**：写 spec / `CONTEXT.md` 时写「强 AI 基线」，具体是谁只写在 NOTICE、报告与页脚。
   **修订（2026-08-19，票 102，主人直接要求）**：具名的落点从「NOTICE / 报告 / 页脚」
   **扩到用户遇到它的那一刻**——配桌页拨到那一席时那一句说明、牌桌上「正在取那几 MB」与「已就位」
   那两句、以及降级那一句的句末。理由：页脚那条链接尽的是 Apache-2.0 §4(d) 的**义务**，
   而「这是什么、谁做的」是**用户在决定要不要用它时就该看见的事**，藏在一个要点开的页面里等于没说。
   **通名仍是术语**（面板按钮、名牌、牌谱 `names` 那一列一个字没动），
   具名只出现在署名与说明处；页面侧的唯一真源是 `src/Janpo.Web/Credit.fs`，
   事实的唯一真源仍是随站点分发的 `web/public/third-party/README.md`。
6. **CI 里跑不跑真推理由数说话**：89 ms/半庄 意味着跑得动，但 6 MB 的产物**不入版本控制**
   （`probe/akagi-wasm/.gitignore` 已排掉 `dist/ target/ .upstream/`，重建走 `fetch-upstream.sh`）。
   CI 若因此覆盖不到某一段，**必须在报告里写清覆盖不到什么**（判据 4）。

## 后果

1. **权重的语料来源不可核，风险由我们承担。** 三处独立出处互证「行为克隆自天凤牌谱」
   （`native_bot/README.md`、`train/README.md`、`src/defaults.rs`），
   但**仓库里没有数据集名、没有 URL、没有 model card**，仓库外也查不到。
   Apache-2.0 授权的是上游对**代码与权重文件本身**的权利，**不代表天凤牌谱的权利人授权过什么**。
   主人 2026-08-19 裁定：**照原样分发，风险记在案**——`NOTICE` 里白纸黑字写明
   「上游声明其行为克隆自天凤牌谱；具体语料出处上游未公开，我们无从核」，**不假装它清楚**。
   （上游自己已经这样公开分发；这不构成我们的抗辩，只是事实。）
2. **「自己重训」是一张备选票，不是本决定的前提。** 管线现成（上游 `extract` + `train.py`，
   声称 4070 Ti 上 5 分钟），我们手里有 12,188 场说得清来源的牌谱。
   它同时解决许可与「强度是否可控」（弱/中/强三档当刻度）两件事——**等强 AI 那条线真的立住之后再议**。
3. **对照物有了地板。** M3 的复盘对照标注（票 90/93）此前只能靠引擎自算的量（向听/有效牌/危险度）；
   强 AI 可用之后可以叠一行「此手强 AI 会怎么打」，而**引擎自算那一层不许被拿掉**
   ——零依赖的复盘是产品底线（M3 起草时主人已裁）。
