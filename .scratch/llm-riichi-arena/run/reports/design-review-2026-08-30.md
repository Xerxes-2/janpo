## P0 · 把「打完了」变成「有结果」（三条都不动引擎、不动牌谱格式、不需要后端）

- **P0-A 终局记分卡**：终局屏给一张四行的表（席位 · 选手带脚手架档 · 顺位/终点 · 和了·放铳·立直 ·
  兜底手数 · 重试次数 · 输入/输出 tok），再给一枚「复制记分卡」：纯文本 + PNG。
  病：四家之间没有一张可比的表；跑完了没有地方放结论。⇒ 票 133 / 134
- **P0-B 本机累计战绩**：终局时按（模型 · 脚手架 · 规则 · 种子）追加进 localStorage；
  首页一张小表（场数 / 平均顺位 / 兜底率 / 平均 tok）。不上传、不聚合、只属于这台浏览器。
  配「导出 CSV」与「清空」，写明这是几场记录、不是评测。⇒ 票 135
- **P0-C 对局中的右轨**：右轨常驻刚落子那一席的全文 + 三个元数字（延迟 · 重试 · tok），
  播放时自动跟随、单步时钉住；其余三席仍是药丸。信息辅助接在下面。
  代价：纵向上限 + 内部滚动，不许推动牌的尺寸。⇒ 票 136

## P1 · 第一眼与第一步

- **P1-D 首页不该停在第 1 手**：时间轴带上记号（值得看的那几手 + 兜底 / 重试 / 格式跑偏）、
  落地位置放到第一个「值得看的」那一手、顶上一句可点的「它为什么打这张？」、分享链接带手数。⇒ 票 137
- **P1-E 开桌从七步压到一步**：抽屉最上面一行 `provider · 模型 · key ·〔开打〕`；
  其余收进「进阶」；key 那栏右边就地写明「只写进这台浏览器的 localStorage」。⇒ 票 138
- **P1-F 一个读者，四家不必等大**：所看那一席 1.35×、其余三家 0.9×；
  顺手把桌心五项改横排、本場与供託画成棒。⇒ 票 139（**后半已由「牌桌救援 票 5」做掉**）

## P2 · 方向，不急着做

- **P2-G 双回放并排**：两份牌谱同屏、按手数对齐、只差一个变量。第一版只做「导入两份 JSON 并排看」。⇒ 票 140
- **P2-H 一屏英文说明**，不做全量 i18n。⇒ 票 141
- **P2-I 手机：不救牌桌，换一种页面**——竖屏给一个「读」的版式。⇒ 票 142

## 不建议做的（原文照录）

- 任何后端 / 账号 / 云端排行榜。「没有服务器接得到你的 key」是这个项目最强的一句话，换排行榜不值。
- 动效补间。纸面牌谱的气质靠静态与留白。
- 把手机牌桌救回来。390 px 上四家 34 张牌是数学问题，不是 CSS 问题。
- 首页再加解释文字。该减不该加。
- 去掉 provider 前缀来省列宽。票 118 已经量过：11 px 字号 + 256 px 列宽下最长的真名还有 16.6 px 余量。
