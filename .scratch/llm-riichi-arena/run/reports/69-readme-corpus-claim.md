## 3. 对票面措辞的一处小修（已记 DECISIONS「## 69」）

它是年代口径（当年天凤允许食替、引擎实现现代口径），牌谱数据本身既无缺口也无异常。
照原句写，将来逐词审计就得删（正是本票自己引的判据）。处置：括号里多列一类
「或早年对局打的是当年的规则」，其余照票面。这是往**更核得实**的方向修，不是放宽。
