## 2. 气泡：收起是药丸，展开是浮层

主人给的话：「准许覆盖其他元素」「随时点击收起或者展开」「收起状态就只有小气泡」。

做法是**原生 `<details>`**——**不新增 model 状态、不加消息**。
「哪一席的气泡开着」是纯粹看的状态：不该进牌谱、不该进分享链接、
也不该让 `Playback` 多一代。点 `<summary>` 开、再点收，两个方向都是浏览器给的。

收起态实测 **31×19 px**；展开态 `position: absolute`，**不挤占任何元素**。
自家那一席**往上**展开（往下会撞页脚，实测浮层 742→790 而页脚从 786 起）。

## 3. 闸门换契约：撤一条，补四条

**撤**：「气泡不许与牌 / 河 / 副露 / 牌桌中央相交」——主人明许覆盖，
再守它就是守错了东西。**覆盖率不能凭空消失**，∴：

| 新断言 | 反证 | 报的话 |
|---|---|---|
| ① 收起态（药丸）不许压牌 | （与②同源，②先红） | — |
| ② 收起态尺寸有上限（≤4 牌宽 / 2 牌高） | 药丸设 `width: 20rem` | 「收起时宽 269 px，超过 4 张牌宽（90 px）：那不叫收起」 |
| ③ 浮层要挨着它自己那枚药丸 | 浮层设 `top/left: 30rem` | 「离它自己那枚药丸 358 px（上限 45 px）：它飘走了」 |
| ④ 点得开**且**点得收，四席各走一个来回 | 让它一开局就带 `open` | 「座位 0 的气泡一开始就是开着的：收起态才该是常态」 |

②的上限按**牌宽的倍数**算，不写死 px——固定舞台会缩放（票 119）。
③接替原先的「气泡得画在那一席的框里」：浮层现在本来就该探出那个框，
但**一个飞到页面角上的浮层与谁都不相交**，没有这一条的话下面全绿。
④两个方向都要：只验「点得开」的话，一个开了收不回去的气泡照样全绿——而它会一直盖着牌桌。

## 4. 本轮四条断言，三条第一版是坏的

| 断言 | 坏在哪 | 怎么发现的 |
|---|---|---|
| 操作条↔牌桌间距（票 83 移植） | `max(0, min(vertical, horizontal))`——并排时纵向重叠是负数、min 取到它，**恒等于 0**。拉开 6rem 都不报 | 阴性对照 |
| 「一开始就是开着的」 | 先「若开着就点收」再问「是不是开着的」，**那一问永远为假** | 阴性对照（`open` 破坏打不中） |
| 「点得开、点得收」那一圈 | 开头一句 `continue` **静默跳过**——本项目明令禁止的形状 | 加计数后自报「4 席各走了一个来回」 |

**共同形状：断言存在、能跑、退 0，而它守的不是那件事。**
阴性对照打不中 ⇒ 断言是空的或比声称的弱——这一条本轮兑现了三次
（加上票 119 的③，四次）。
