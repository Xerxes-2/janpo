# 111 — 撤票之后：牌桌自己动起来 + 给 `VoidCause.Expired` 那条防御分支一个执行者

浏览器 **19 趟**——**一趟都没加**，第一件那道断言长在票 108 立的第 19 趟里）。

**结论先说五句。**

1. **第一件做完了，做法是「拨完座位把牌桌按它此刻的播放状态重新推一记」**（`roused`）：
   播着的桌自己接着走（那一席按新配置被重新问出去），**停着的桌拨完还是停着**。
   30 颗种子打完 30 整场实测：拨那一下**自己续上定时器 128 次 / 128 次**（修前 **0 次**）。
2. **阴性对照单独一条，而且它的阳性对照停在同一处量点上**（判据 20）：同一张牌桌、同一下拨动，
   停着时只发落 localStorage 那一记（1 个效果体）、播着时发两个。少了后半句，那条阴性对照
   就只是在量一张「本来就不会发定时器的桌」。
3. **真人席那一支一个字都没破**（票 87/88/89）：拨给真人那一下**一记定时器都不发**（`waiting`），
   而且**播放状态原样留着**——他出完手这一桌照旧接着走。就算真有一记定时器回来，
   它也只把牌桌空转一遍、不替他打。
4. **第二件：构造出来了，不是不可达。** 那条防御分支现在有一个单元级的执行者
   （`牌桌绕过一份在飞的问话往前走：剪枝剔掉它，账上记一笔「过期」`）：一旧一新两份包挂在同一席上，
   走 `drain` 那条路，**旧那份被剪掉、账上一笔 `cause = Expired`、一条决策记录都不多**，
   而新那一票原样在飞。**三把反向自证各红一次**（§⑤）。
5. **两个计数**（量点停在**那一场真的打完之后**，判据 20）：30 颗种子 / 30 整场 / 128 局，
   每局在头一次在飞问话上拨一次座位 → **撤票 128 次、剪枝 0 次**。
   剪枝在真对局里仍旧是 0——**这正是它需要一个单元执行者的理由**，不是它可以删掉的理由。

### 1.2 绿：`roused`（`src/Janpo.Web/TableState.fs`）

```fsharp

    match model.Source with
    | Source.Replay _ -> model, cmd
    | Source.Live _ ->
        let playback = Playback.resumed model.Playback.Playing model.Playback
```

## ② 阴性对照：停着的桌不会凭空开动

用例 `阴性对照：本来停着的那一桌，拨一下座位不会凭空开动`：

- 单步（`Advanced`）过来的那一桌**停着**（`Playback.Playing = false`），在飞一票；
- 拨给别的模型：**撤票照旧发生**（那不是这条要量的东西），而
  - `Playback.Playing` 仍是 `false`，
  - 这一条消息**只发一个效果体**（落 localStorage 那一记），
  - 随后就算喂一记当前世代的 `Ticked`，牌桌手序不动、一票都没问出去（暂停时它本来就被 `accepts` 丢掉）；
- **阳性对照就在同一处量点上**：同一张牌桌先按一下「播放」，同一下拨动当场变成两个效果体。

## ⑤ 第二件：**构造出来了**（那条分支现在有执行者）

### 5.1 构造法

用例 `牌桌绕过一份在飞的问话往前走：剪枝剔掉它，账上记一笔「过期」`：

1. 问出去一票（`ghost`，包是第 0 手那一份）；
2. **让它答上来、真落成一手**——牌桌往前走了，这份包从此是旧的；
3. 推到那一席**又被问一次**（`fresh`）：这一份包量的就是「引擎此刻给这一席的合法动作集」；
4. **把旧那一份原样挂回在飞表里**（`reflown`，测试侧唯一一处直接摆弄 `LiveTable` 的地方）：
   同一席上一旧一新两份包，旧那份指着已经翻篇的那一手；
5. 走 `drain` 那条路（`Advanced` → `step` → `drain` 顶上那一道）。

**阳性对照防的是「验成了另一种过期」**：断言此刻那一席**确实在待答之列**、
它的合法动作集**等于新那一票包里那一列**、且**不等于**旧那一份。
不写这两句的话，「那一席根本不在待答之列」也会被剪掉——那是同一道 `stillCurrent` 的另一条腿，
拿它验就是在验另一件事。

断言（票面那三件逐条）：**剪掉的只有旧那一份**（`[fresh.Ticket]` 仍在飞）、
**账上一笔 `Cause = Expired`**（`VoidedAsk.reason` 里那句「翻篇」）、**`Table.revoked` 是空的**
（撤票与剪枝两个数分得开）、**手序 / 事件流 / 决策记录一个字都没多**；
随后那一笔的回执晚回来，**钱补进账**（`Table.usage` 恰好多出那一份账单、`paidVoids` 1 笔），
而决策记录仍旧只有真落定的那一条。

### 5.2 为什么它今天在页面上走不到（**但那不叫不可达**）

- 牌桌只有三处会绕过 `drain` 的顺序往前走：`HumanPlayed` / `HumanTicked`（都走 `handOf`）、
  以及重开 / 开下一局（`Restarted` 整桌换新、`KyokuAdvanced` 走 `turned`）。
- 走 `handOf` 要那一席是**真人**，而变成真人只有 `SeatBound` 一条路——**它现在当场撤票**（票 109）。
- 响应阶段**收齐才裁决**（票 108 §1.1 扫过 80 场 0 例），因此「别人答了，我这一席的待答凭空散掉」不成立。
- 于是**今天没有一条页面上的路**造得出「一份在飞的问话 + 牌桌已经绕过它往前走了」。

**这正是判据 3 说的那种情形，而处置不是删**：那条分支守的是**将来**新长出来的绕行路
（例如「下一局」变成局中点得动、或者 `Fault` 之后 `Table.pendings` 变空那一种）。
本票按调度器的裁定给了它一个**单元级的执行者**：从此「从不发生」与「发生了被静默吞掉」分得开。
