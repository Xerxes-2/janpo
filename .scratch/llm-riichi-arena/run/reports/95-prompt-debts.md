## 1. 债一：prompt 里混着几套记法，收成一套

### 1.1 改之前到底有几套

不是票面写的那三套，是**三处第二套写法**（英文动作词一次都没出现过——它是**将来会漏进来**的那一种，
见 §4.3）：

| 位置 | 改前 | 谁渲的 |
|---|---|---|
| 手牌 / 牌河 / 副露 / 宝牌指示牌 / 历史那几行 / 脚手架算好的那几个数 | `3s`、`5mr`（mjai） | TS，从决策包原样搬 |
| **【可选动作】那几行、逐张试打、危险度排序** | `手切3索`、`摸切发`、`碰赤5筒（亮5筒 5筒）` | **引擎**（`Action.toDisplay`），TS 照抄 |
| **场风与自风** | `东1局`、`（北家）` | TS，查 `wording.kaze` 那张表 |
| **手切 / 摸切** | 动作那一行写「手切」「摸切」，牌河与历史写 `*` | 同一件事的两种记号 |

第三处最贵：**役牌正压在这条翻译上**。模型读到「东1局」「你是座位 3（北家）」，
手里那几张字牌却写着 `1z` `4z`——它得自己把两边对上才知道自己有没有役牌。

### 1.2 改之后

```
【现在】
场风 1z・第 1 局 0 本场，供托 0 根。
宝牌指示牌：6p　牌山剩余可摸 65 张。

【你的手牌】
你是座位 3（自风 4z），第 1 巡，25000 点。
手牌：4m 7m 3p 5p 5pr 1s 1s 3s 4s 5s 5s 7s 3z 6z（14 张）

【其他三家】
下家（座位 0・自风 1z）：手里 13 张，第 1 巡，25000 点，立直：无
对家（座位 1・自风 2z）：…　副露：碰 1z（来自他的下家，亮出 1z 1z）

【可选动作】只能从下面这些 id 里选一个：
- id=0：打 4m
- id=4：打 5pr
- id=10：打 3z
- id=11：打 6z*          ← 摸切缀 `*`，与牌河、历史同一个记号
```

三处改法：

1. **可选动作那一行改成 TS 现渲**（新文件 `web/src/agent/action-label.ts`）：
   从 `ActionOption.action`（就是一条 mjai 动作消息）念出来，**牌照 mjai、五种副露的词照措辞表**
   ——与 `history.ts` 渲一条事件走的是同一条路、同一份 `Words`。
   **引擎那份中文 label 一个字没改**，它照旧给牌桌上「上一手：座位 1 手切1万」那行字用
   （`TableBoard.fs`）：中文仍旧只活在给人看的那一侧，正是 ADR-0001 要的形态。
2. **场风与自风写成 `1z`-`4z`**：`DEFAULT_WORDING.kaze` 默认那一份改成恒等
   （表**留着**——它仍是模板的一个槽位，要一份给人读的中文模板，整表换掉即可）。
   句式跟着改成 `场风 1z・第 1 局` 与 `（自风 4z）`：`1z1局` 两个数字挨着读不动。
3. **手切 / 摸切统一成 `*`**：动作那一行写 `打 5s` / `打 5s*`，读法在 preamble 里只说一次。
   **动作 id 仍是唯一的接头**，赤 5 与正 5、手切与摸切各是一条动作、各有各的 id
   ——`5m` 与 `5mr` 分得开、`*` 分得开手切摸切，「同一包里两条动作那一行不许相同」
   这条性质**重新证了一遍**（`prompt.test.ts` 里新增的那条用例，18 份固件逐包核）。

**认不出来的动作退回引擎那份中文 label**（`labelOf`）：mjai 将来多一种动作时，
宁可那一行写着中文也不能让这一手渲不出来。**退回去是看得见的**——新那条不变量当场把它抓出来。

### 1.3 preamble 里那份「读法」也不许带中文牌名

改前 preamble 自己就写着 ``牌用 mjai 记法：`3m` 是万子 3、`7z` 是中``——**它就是那本字典**，
留着等于承认 prompt 里还有第二套。改成结构化地说：数牌三门、字牌七种、`1z`-`4z` 是风牌、
`5z`-`7z` 是三元牌，红 5 写 `5mr`。全文自此一个中文牌名都没有。

## 4. `verify-invariants` 逐条交代（一条不许少、一条不许放宽）

**改前**：11 条不变量 + 1 道对拍、14 个反向自证。
**改后**：**12 条不变量 + 2 道对拍、20 个反向自证**。**原来那 11 条一条没删，14 个自证一个没少**，
其中 **11 条不变量的判据一个字没改**、**1 条只改了它读的记法**，另有 6 个新自证。

### 4.1 原样保留、判据一字未动的十一条

`prompt 解析得动` / `吃恒来自上家` / `副露来源的参照系` / `暗杠不带来源` / `副露的张数` /
`河牌数与巡目` / `宝牌指示牌数与杠数` / `立直后全摸切` / `手牌张数 3n+1 / 3n+2` /
`同一牌种最多 4 张`——这十条读的是【副露】【牌河】【手牌】【宝牌指示牌】与历史那几行，
**这一票一个字节都没动它们的句式**，因此判据、口径、执行次数全部照旧（数字见 §4.4，与改前逐个相同）。

第十一条 `可选动作的牌来自手牌` 是**唯一被这一票动到的**：

| | 改前 | 改后 | 为什么等价 |
|---|---|---|---|
| 读的东西 | 动作 label（中文牌名） | 动作那一行（mjai 记法） | 被检查的**那一行本身换了记法**，不是判据换了 |
| 判据 | label 里「必须出自你手里」的那几张，逐张在【你的手牌】里**按多重集**扣掉 | **一字不改** | 强度同一：暗杠仍要手里真有四张；碰 / 吃 / 大明杠仍只数亮出来的那几张（鸣来的那张来自别人的河）；荣和那张仍不算 |
| 中间那份中文↔mjai 的表 | `tileOfDisplay`（闸门自己认一遍中文） | **没删，搬到 `label-crosscheck.ts` 当第三锚点**（§4.2） | 两侧仍是两份互相独立的实现 |
| 执行次数 | 13,842（一条动作一次） | **13,842**（一模一样） | 口径没变 |
| 反向自证 | 「把一条打牌动作换成一张手里没有的牌」 | 同一条，牌名从 `手切{中文}` 换成 `打 {mjai}` | **注的是同一种错**，只是写法跟着换 |

它的反向自证在真语料上照旧当场红：

```
[可选动作的牌来自手牌] 均匀 种子 7・座位 0・第 0 手・bare 档：这条动作要出的「2m」不在你的手牌里
    原文：- id=0：打 2m
    手牌：1m 7m 3p 3p 4p 5pr 7p 2s 2s 3s 5s 6s 4z 5z
```

### 4.2 新增：第十二条不变量 + 第二道对拍

**第十二条 `记法只有 mjai 一套`**（`invariants.ts` 的 `checkMjaiOnly`）——三个方向：

1. **场风与自风**必须是 mjai 记法（它们指的就是手牌里那张字牌）；
2. **可选动作那几行点名的每一张牌**必须是 mjai 记法（认不出动作退回引擎中文 label 时，这里当场红）；
3. **全文两遍扫描**：中文数牌名（`赤?[0-9一二三四五六七八九][万萬筒饼餅索]`）与
   mjai 的动作 wire 名（`\b(dahai|tsumogiri|tsumo|pon|chi|ankan|daiminkan|kakan|reach|hora|ryukyoku|none)\b`）
   一个都不许出现。

**为什么字牌的中文名不扫全文**（这是个自觉的口径，不是漏）：`中`、`东`、`西` 同时是常用汉字
——人格里的「中庸」、行文里的「其中」会当场假红。字牌因此只在**「点名一张牌的地方」**被查，
而那些地方合起来是全的：

| 一张牌出现在哪 | 谁在守 |
|---|---|
| 手牌 | 第八条 `手牌张数` 里那圈 `TILE.test`（既有） |
| 牌河 | 第五条 `河牌数与巡目`（既有） |
| 副露的 pai / consumed | 第四条 `副露的张数`（既有） |
| 宝牌指示牌 | 第六条 `宝牌指示牌数与杠数`（既有） |
| **场风 / 自风** | **第十二条**（新） |
| **可选动作那几行** | **第十二条**（新；改前它是「用中文表反查」） |
| 脚手架算好的那几个数、历史那几行 | **第十二条的全文扫描**（新） |
| 散在自由文本里的单个字牌名（例如人格写「打中」） | **抓不住**——那不是记法债，是人写的话 |

**第二道对拍 `动作那一行 ↔ 引擎的中文 label`**（新文件 `web/tests/agent/label-crosscheck.ts`）。
理由是判据 18：改记法最怕的不是难看，是**把动作说错**——少一张亮牌、把碰写成吃、把赤 5 写成正 5，
这几种错在纯文本里全都自洽，那十二条一条也看不见。它拿**引擎自己渲的中文 label**当第三锚点
（`Action.toDisplay`，F# 写的，这一票一个字没改），逐条比「是哪一种 + 点名了哪几张牌（多重集）」。
两侧是两份互相独立的实现，各自从同一个 `Action` 出发。**真语料上对拍了 13,842 条动作**：

```
「动作那一行 ↔ 引擎的中文 label」对拍了 13842 条动作：
  ankan 42　chi 216　dahai 11954　dahai* 1260　daiminkan 10　kakan 12　none 254　pon 86　reach 6　ryukyoku 2
```

`hora-tsumo` / `hora-ron` 这两格**这一趟一次都没走到**（`janpo decide --sequence` 只走打牌那一路），
因此防空转名单里**没有把它们凑进去**（判据 4：到不了的要显式写出来，不塞进必覆盖名单）。

### 4.3 记法闸门的阴性对照：**它红了，红成什么样贴在这里**

三个反向自证，全都在**真语料**（1,602 份真实对局渲出来的 prompt）上跑，各自当场红：

```
[记法只有 mjai 一套] 均匀 种子 7・座位 0・第 0 手・bare 档：prompt 里出现了中文牌名「1万」：中文只活在给人看的那一侧（ADR-0001）
    原文：- id=0：手切1万
    （同一处顺带红了：可选动作的牌来自手牌）
[记法只有 mjai 一套] 均匀 种子 7・座位 0・第 2 手・bare 档：prompt 里出现了 mjai 的动作 wire 名「pon」：那是数据层的词，不是写给模型看的话
    原文：对家 第1巡 pon 下家打的 2z（亮出 2z 2z）
[记法只有 mjai 一套] 均匀 种子 7・座位 0・第 0 手・bare 档：场风写成了「东」：它指的就是手牌里那张字牌，该写 mjai 记法（`1z`-`4z`）
    原文：场风 东・第 1 局 0 本场，供托 0 根。
```

**第一条那个变异不是手捏的**：它把那一行**原样退回票 95 之前的写法**（`Tile.toDisplay` 的中文牌名
+ 「手切 / 摸切」两个词）。也就是说——**把这一票的改动在一行上撤销，闸门当场红**。

第二条演的是「英文动作词」真会怎么漏进来：`wording.ts` 的 `lookup` 在措辞表查不到时
**把 wire 值原样写出去**，`history.ts` 遇上读不懂的事件也一样。改前改后真语料上都是 0 命中，
但它不是空转——见下一节的执行次数。

另外三个新自证在第二道对拍上（后两个是**纯文本那十二条按设计看不见**的那种错，
脚本里对这一点有阳性断言：它们要是被文本那边红了，说明变异挑得不对，当场喊停）：

```
[动作那一行 ↔ 引擎的中文 label] …：渲出来点名的是 1m 9m 9m，引擎那份 label「碰9万（亮9万 9万）」点名的是 9m 9m 9m
```
