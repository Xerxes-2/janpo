## 2. 形状：一个模块，三个消费点

新文件 `src/Janpo.Web/Credit.fs`（排在 `SeatingPlan.fs` 后、`BaselineLine` / `TablePanel` / `Footer` 前）：

```fsharp
Credit.author / licence / sourceCommit        // 上游的版权人 / 许可 / 我们取的那一版
Credit.baselineNamed / baselineBadge         // 「Akagi 的 native_bot」/ 它 + 许可
Credit.thirdPartyFile / thirdPartyText / thirdPartyUrl ()   // 那份声明的路径、链接上的字、完整地址
Credit.baselineIntroHead / IntroTail / baselineIntro        // 配桌页那一句（中间断开处是那条链接）
Credit.baselineSaid : BaselineStatus -> string -> string    // 牌桌上四态各一句
```

三条判断：

1. **具名只写一处。** 从前页面上「强 AI 基线」四个字硬编在 `BaselineLine` 里，而
   `SeatingPlan.baselineToDisplay` 的注释写着「面板上那枚按钮、牌桌上的名牌、**状态线上那句话**
   读的都是它」——**那句话当时是假的**（状态线自己写了一份字面量）。这一票让它变成真的：
   四句话都插 `SeatingPlan.baselineToDisplay`。这是本项目那个常见错的又一例
   （记录声称了一件事，而执行体不存在），只是这次代价为零。
2. **那四句话搬进不 open Feliz 的模块**，于是 dotnet 用例够得着它们——**CI 里的浏览器摸不到
   `Ready` 那一态**（那 6 MB 不入版本控制，ADR-0006 边界 6），只有 dotnet 那一侧钉得住它。
   画在哪儿仍旧是视图的事（`BaselineLine` 只管颜色与 `data-*`）。
3. **配桌页那一句挂在「拨上了才画」后面，页脚那一条不挂在任何条件后面。** 两者分工：
   前者是「用户看得懂这是什么」，后者是分发件的法律义务（§4(d)）。闸门把这条分工也钉住了
   （没拨那一席的页面上，页脚那条链接必须**恰好 1 条**）。

## 3. 闸门

| 在哪 | 是什么 | 停在哪一刻 |
|---|---|---|
| `tests/Janpo.Web.Tests/BaselineCreditTests.fs`（+7 条） | 那几句话说得对不对：四样齐、一句话量级、`Ready`/`Loading` 里有名字、`Unavailable` 语义不退化、`Absent` 一个字不说、通名里不许出现具名 | —— |
| `web/scripts/verify-baseline.mjs` 第 ⑤ 趟（新增） | 那几句话到没到人眼前 | **拨上之前 / 真点那一枚之后 / 正在加载 / 掉下来**，四个量点 |
| `scripts/check-pages-dist.sh` 第 ④ 件（新增） | 发布件里找得到那条路径与具名 / 作者 / 许可 / 来源 commit | 发布那一刻 |

**第 ⑤ 趟怎么停在那一刻上**（判据 20）：`context.route` 把那次资产请求**按住 3 秒**再让它失败，
于是「正在加载」这一瞬间变成一段可断言的窗口；同一趟里等它掉到 `unavailable`，两句话都不靠运气。
**顺序还踩过一脚**：第一版先在配桌页那一句上等满 5 秒超时，回头再读状态线时它早已掉到
`unavailable`——一次破坏于是多红一条「loading 没到过」，让人找不到北。现在先读状态线
（只在那一瞬间存在），再读配桌页那一句（与它是同一次渲染的两半，晚一点读也还在）。

  **超出票面做的两件事**：README 的 WIP 段与脚手架第三档那两句（同一族的文档空转，
