# 88 — 真人的响应动作：吃碰杠、立直、荣和、自摸

**结论：票 87 那条「响应阶段一律自动过」整个没了——吃碰杠、立直、和了、九种九牌与「过」
各是一枚真按钮，而每一枚背后都是引擎给的一条 id。** `./scripts/ci.sh` **EXIT=0**，53.9s；
dotnet 748 + **243** 条（原 748 + 228），浏览器仍是十五趟，`verify-human` 从 2.3s 变 **3.5–3.8s**
（多跑了第二程：一整场门清立直的对局）。

四件事落地：① `TableState.handed` 那一支删掉了——**两种轮到合成一条路**：把包摆在页面上等一次点击；
② 牌桌**下面**多了一排按钮（`HumanLine.calls`），条数与内容全部现问那一份决策包；
③ **立直两段没有新状态**：宣言之后仍是同一个 `humanTurn`，那一手的合法动作集自己只剩
「打完仍听牌」的那几张；④ **并发**：真人在想的时候模型席照问照答（`step` 那道早退拆了），
而落子仍旧沿引擎待答的顺序走——**谁先答不改裁决**。

**闸门漏过一次，是自己按红时抓到的**（§5 红-3）：把票 87 的自动过按回去，
第一版的浏览器闸门**全绿**——因为它从不在「他有按钮」的时候按「单步」。补了两条断言
（dotnet 一条、浏览器一条）之后那次破坏才红。

## 1. 形状：一处接缝、三个出口、一条消息

| 层 | 票 87 | 票 88 |
|---|---|---|
| `TableState.handed` | 有「过」就替他提交，记一条 `AutoPass` | **整个函数没了**：`drain` / `step` 的 `Demand.Human` 那一支原样返回 |
| `TableState.handOf` | 头一家是他**且这一包里没有「过」** | 头一家是他就行（**响应阶段同样停下来等他**） |
| `HumanSeat` | `dahai` / `dahaiOptions` / `passAction` / `unspoken` | `dahai` / `dahaiOptions` / **`buttons`** / **`pass`** / `kind` / `declaringRiichi` |
| 记账 | `AutoPass`（平台替他过掉了什么） | **`HumanPass`**（**他自己**放掉了什么），钩子 `data-human-passes` 没换名 |
| 消息 | `HumanPlayed of id: int` | **一个字没改**——吃的左中右与碰的赤 5 取舍在包里早就各占一条 id |

`HumanPlayed` 不必加 case 这件事是这一票最省事的一处：跨界回来的仍旧只有一个整数，
**页面照样构造不出一个 `Action`**（spec 的 story 30 在结构上成立）。

### 1.1 三个出口合起来正好是那一包

```fsharp
HumanSeat.dahaiOptions package   // 画在自家手牌上（票 87）
HumanSeat.buttons package        // 牌桌下面那一排：吃 / 碰 / 杠 / 立直 / 和了 / 九种九牌
HumanSeat.pass package           // 那一排最后一枚：「过」
// 三者的 id 合起来 = DecisionPackage.options 的 id，一条不多一条不少
```

**这就是票面的要害判据**（「找不到 id 的按钮不许存在」），而它被写成了**双向**的一条：
多一枚是页面凭空造的，**少一枚是引擎给了他却点不到**。dotnet 一整场每一手核一遍（89 次），
浏览器每一次出手也核一遍（第一程 89 次、第二程 100 次上下）。

`ActionButton = { Id; Kind; Label }` 三格全部照抄包：`Kind` 是 **mjai 的动作名**
（`chi` / `pon` / `daiminkan` / `ankan` / `kakan` / `reach` / `hora` / `ryukyoku` / `none`，
裁决 D-1 的拼法），给机器看；`Label` 是引擎给的中文，给人看。**`CONTEXT.md` 一个词都没加**：
`ActionButton` / `HumanPass` 是渲染层的名字，日麻术语一个没自造。

### 1.2 立直两段：没有新状态

宣言之后**仍旧是同一个 `humanTurn`**——引擎的合法动作集在 `RiichiState.Declared` 那一支里
只剩「打完仍听牌」的那几张（`GameState.awaitingDahaiActions`）。页面因此一条规则都不必判：
**那一手能点的牌自己就变少了**。页面只多读一件引擎的事实（`Observation.Self.Riichi` 是不是
`Declared`），为的是**把话说对**：那一手能点的牌突然少了一半，不说一句人会以为页面坏了。

`data-human` 因此有五态：`waiting`（该他出牌）/ `respond`（他家打了牌，等他）/
`reach`（宣言了，正在选宣言牌）/ `watching` / `settled`。

### 1.3 并发：`step` 那道早退拆了

票 87 的 `step` 头一句是「轮到真人就整个不推」。响应阶段同时等好几家，那一句会把
**同一轮里待答的模型席一起堵在他后面**（票 74 治的正是这个）。改法两处：

```fsharp
// step：早退删掉——上面那趟「把待答而没在飞的席全问出去」照旧跑，
//       只是最后落子那一步遇到 `Demand.Human` 时停住。
// waiting：「只能干等」= (有在飞的回执 或 轮到他) 且 **没有待答而没问出去的模型席**
let private waiting (roster: Roster) (live: LiveTable) : bool =
    (not (List.isEmpty live.Awaiting) || Option.isSome (handOf live)) && not (unasked roster live)
```

于是他在想的时候那一记定时器还转一下、把该问的问出去，问完就停（不空转）。
**落子顺序一个字没动**：`drain` 仍按引擎待答的头一家落，模型的回执在 `Awaiting` 里等他。

**`handOf` 仍旧只看头一家**（`Table.pending`）而不是「他在不在待答之列」：让他提前插队会把
同一轮里模型席的决策记录手序号弄偏一位，于是牌谱与逐帧回放对不上（`drain` 那段注释）。
代价是：他与模型席同轮待答、而模型排在他前面时，他要等模型答完才拿到按钮——**与模型席完全同级**。

## 2. `AutoPassed` 的语义变了（记账留着，钩子没换名）

| | 票 87 | 票 88 |
|---|---|---|
| 类型 | `AutoPass` | `HumanPass` |
| 字段 | `Turn` / `Seat` / `Skipped` | **一个字没改** |
| 语义 | 平台替他过掉了这几条 | **他自己按「过」放掉了这几条** |
| 页面 | 「第 341 手替你过了：碰南（亮南 南）」 | 「第 366 手你按了「过」，放掉了：碰北（亮北 北）（这一桌共 18 次）」 |
| 钩子 | `data-human-passes` | **同名同义**（他按了几次） |
| 取值器 | `TablePage.autoPasses` | `TablePage.passes` |

**为什么不留「自动过」那一支**：留着就有两种「过」，而页面上分不出哪一次是他自己按的
——而那正是复盘（票 90）第一件要问的事。**票 89 的时限要加「到点自动过」时**，
这条记录要能说出「这一次不是他按的」，那一格由那一票加，本票不预留空字段（判据 2 的反面：
预留一个没人填的字段等于写下一条没有执行者的不变量）。

### 4.2 浏览器侧（第十五趟 `verify-human.mjs`，3.5–3.8s；**一个字节都不出网**）

- **他在想的时候替他按一记「单步」**：牌桌一手都不许动（红-3 补的那一条）；

**第二程**（真人 + 三家 bot、**种子 427 写死**、门清立直那套代点）：
