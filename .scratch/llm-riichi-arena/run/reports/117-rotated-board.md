# 117 — 四席绕盘心：牌桌换成标准麻将几何

**状态**：done（`./scripts/ci.sh` 全绿，EXIT=0）
**基点**：`qwmyyroo`（117 之一，正文黑体）
**改了**：`TableBoard.fs`、`styles.css`、`verify-board.mjs`、`naki-marks.mjs`

## 1. 做了什么

一席**拆成两半**：

| | 装什么 | 转不转 |
|---|---|---|
| `.zone` | 副露、手牌、河 | **绕盘心 `rotate(0/90/180/270)`** |
| `.seat`（名牌卡片） | 名字、点数、巡目、记号、气泡 | **不转** |

牌面转了照旧认得（真牌桌就是这么摆的），而名字、点数、气泡里那段推理倒着就没法读——
**屏幕前只有一个读者**，不是四个围坐的人。

四席**同一份 DOM**，里面一律按「坐在下方那一家」摆，画到哪个方位只由 `data-seat-position`
（`Board.position` 的输出）定。∴ 方位不是四份布局，是**一份布局的四个角度**。

## 3. 闸门移植：不变量一个字没改，改的只是它到屏幕坐标的映射

| 处 | 改了什么 |
|---|---|
| `naki-marks` 的 `RUN` / `STACK` | 加**符号**。原表只有轴（x/y）没有向，而对家转 180°、下家转 270°，**它们自己的「左→右」在屏幕上是倒着走的** |
| `verify-board.checkHandLine` | 同上加符号 |
| `verify-board` 取节点 | 从「一个节点里什么都有」改成「牌那一半（`.zone`）+ 名牌那一半（`.seat`）」 |
| 「自家在最下、对家在最上」 | **改成量手牌** |

最后那一条值得单说。四个席区都是 `inset: 0` 的同尺寸层、只差一个旋转角，
**矩形一模一样**——实测四家全报 `y=1394`、`x=590`。拿它去问「谁在最下面」
会得到一个四家同值的答案。那不是「方位错了」，是**这条断言问错了对象**：
「这一家坐在哪一边」看得见的那件事是**手牌的位置**，不是席区的框。

`verify-bubbles` 的三条断言（矩形非空 / 气泡在它那一席的框内 / 不压牌与中央）
**一个字没改且全绿**——事先查过全仓库只有一处靠容器关系（`bubble.closest(".seat")`），
∴ 名牌卡片保留 `.seat` 类、气泡留在它里面就够。

## 5. 票面里两条错的，各自更正

**① 「横牌牌面要真横」「白板描边」——真代码里早就成立。**
我照的是**原型的状态**，不是仓库的状态。实测 `.tile.taken { transform: rotate(90deg) }`、
屏幕矩形 38×28（宽>高），牌面走 `background-image` **会跟着元素一起转**；
原型 v2 那个「牌面被压扁」是 `<img>` 写法特有的。白板是票 80-5 做的，
`::after = 1px solid rgb(47,75,110)` inset 3px。
**这是「记录声称的东西没有执行者」那一类错的反面**——记录声称还要做，而那件事已经有执行体。

**② 「标准几何自证方位，那段说明该消失」——前提是错的，没删。**
后半句（「左右两家的牌侧着摆，左→右在屏幕上是上→下」）在**任何**四家围坐的布局里都成立：
上家那一层转了 90°，他的副露行在屏幕上就是竖的。雀魂不印这句话是因为玩家知道约定，
不是因为几何变了。前半句是票 51 立的参照系声明（M1 第六条）。
∴ **改成移出桌心**、挂到牌桌下沿——它是图例不是场况，摆在桌心会把那一格撑到压住四家的河。

## 6. 五个自己踩的坑

1. **相叠的透明层拦住点击**。四层席区都铺满牌桌，DOM 里最后那层（座位 3）挡住真人点自家手牌
   ⇒ 层不接事件、牌自己接。
2. **探出边界的卡片拦住按钮**。名牌盖住上下两排按钮（视角、页脚的 MIT 链接）。
   **靠留白躲不干净**：名牌里可能是 `deepseek/deepseek-v4-flash` 这样的长名，
   换不换行、几行高都随内容变，留白得先猜它有多高——**前两版分别猜错过一次**
   （压 5 枚牌、拦住视角按钮）。最后改成卡片整体不接事件、只有气泡那枚按钮接。
3. **桌心的大小不是自由参数，是河的位置定的**。河带占 `T..T+3行`，四家的带围出的内洞
   = `2T−board`。`T=0.635` 时洞只有 178 px 而桌心 275 px ⇒ 必然压上。
   `T=0.70` → 洞 192 px、桌心 `0.34×board`=163 px，两侧各留 14 px。
4. **一屏预算是量出来的，不是猜出来的**。头一版 1067 px（上限 800）。
   先按量到的分解去收：`seats-board` 上下留白 80→54（名牌已经只有一行高）、
   两行状态字的行间 16→5 px（两行共 112 px，是差额里最大的一块）、牌桌 34→30rem。
   得 795。**中间有一次选择器写成 `.board > .latest` 没匹配上**（父元素没有 `.board` 类），
   量到的数没动才发现。
5. **`biome` 的 `noDescendingSpecificity` 拦了四次**：新规则必须摆在基础规则**之后**。
   这条规则实际上在替我保管一件事——覆盖谁、被谁覆盖，得在文件顺序里看得出来。

## 7. 气泡那一条的解法值得记

自家名牌带气泡时比下方留白高、探到页脚。**横向本来就有大把空地**
（页面 1280、牌桌 480，两侧各 400），而上下两家的名牌原本只铺到牌桌那么宽。
改成 `max-width: min(60rem, 96vw)` 之后那一句一行放得下，名牌回到一行高。
**票 118 会把气泡改成点开的浮层**，这一条到那时就不需要了——它是过渡期的解法，记明。
