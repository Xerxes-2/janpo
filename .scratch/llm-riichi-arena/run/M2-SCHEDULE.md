## M1 传下来的规矩（对 M2 同样生效）

1. **闸门的证据是「它失败过」，不是「它存在」** —— 新增断言必须反向自证一次，红的输出进报告
2. **票号由调度器分配**，agent 只描述问题不编号（M1 撞过一次号）
3. **以截图/DOM 为证据的票，集成时调度器必须把图打开看**（M1 漏过一次，牌背隐形）
4. **查「当下事实」（版本号、API 形状）问权威源**，不用搜索结果的转述（M1 因此漏升了两个大版本）
5. **一个投影里出现第二个「只能从历史算」的字段，就是形态错了** —— 停下来问形态，别加字段
6. **相对方位必须显式声明参照系**；改参照系时要连同「读者以为的参照系」一起改
