# 07 — 役种判定

**What to build:** 一个纯函数：和了牌型 + 上下文标志 → 役种集合与番数，含役满。不含符与点数（08 负责），不含牌型分解的正确性（03 负责）。

**Blocked by:** 03

**Status:** ready-for-agent

- [ ] 覆盖 spec 范围内的全部役种与役满及其复合；不含古役与地方役
- [ ] 门清限定役与可副露役区分正确，副露降番正确
- [ ] 上下文类役依赖传入的标志：一发、岭上开花、海底摸月、河底捞鱼、抢杠、天和、地和
- [ ] Dora（含里 Dora 与红 Dora）计入番数但不作为役
- [ ] 食断开关关闭时，副露状态下的断幺九不成立
- [ ] 无役时判定为不可和（与 03 的和了型判定明确区分）
- [ ] 每个役至少一条黄金用例；互斥与升级关系（一杯口/二杯口、三色同顺/一气通贯、役满复合）各有用例
