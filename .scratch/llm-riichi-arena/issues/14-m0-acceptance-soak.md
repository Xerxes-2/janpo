# 14 — M0 验收：随机对局 soak 与不变量全集

**What to build:** M0 收官。随机 Player 升级为会用全部动作类型（立直、鸣牌、杠、和了）而不只是摸切，然后连续跑大量对局，把 spec 列出的不变量全集架在 soak 上并进 CI。跑完这一票，「四个随机 Player 无头跑完东风战且点数正确」这句验收就成立了。

**Blocked by:** 12, 13

**Status:** ready-for-agent

- [ ] 随机 Player 从完整合法动作集中取样，会立直、会鸣牌、会杠、会和了
- [ ] CLI 能以给定种子范围连续跑 N 场东风战，零异常、零卡死
- [ ] 不变量全集在 soak 中断言：牌数守恒、四家点数与 Kyotaku 之和恒定、任意时刻合法动作集非空或 Kyoku 已终、回放确定性
- [ ] 失败时输出可复现的种子与事件流
- [ ] CI 跑规模适中的 soak（局数可配置），FsCheck 与两类对拍全绿
- [ ] 此里程碑仍不含 Fable、LLM、UI、脚手架与 Danger
