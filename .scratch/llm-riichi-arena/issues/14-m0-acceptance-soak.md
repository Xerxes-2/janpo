# 14 — M0 验收：随机对局 soak 与不变量全集

**What to build:** M0 收官。随机 Player 升级为会用全部动作类型（立直、鸣牌、杠、和了）而不只是摸切，然后连续跑大量对局，把 spec 列出的不变量全集架在 soak 上并进 CI。跑完这一票，「四个随机 Player 无头跑完东风战且点数正确」这句验收就成立了。

**Blocked by:** 12, 13

**Status:** ready-for-human

- [x] 随机 Player 从完整合法动作集中取样，会立直、会鸣牌、会杠、会和了
- [x] **均匀取样不够用，必须加偏好**：调度器在 09 落地后实测四个种子的随机对局，**和了 0 次、立直 0 次**，每一局都是荒牌流局——和了与点数路径在 soak 里零覆盖。Player 必须：有 Hora 就和（或高概率和）、Tenpai 时以一定概率宣言立直、以一定概率鸣牌与杠
- [x] **soak 输出各事件类型的出现频次作为覆盖率证据**，并断言每种动作类型至少出现过一次（hora / reach / reach_accepted / pon / chi / ankan / kakan / daiminkan / 各类 ryukyoku）——否则「覆盖全部动作类型」只是个口号
- [x] CLI 能以给定种子范围连续跑 N 场东风战，零异常、零卡死
- [x] 不变量全集在 soak 中断言：牌数守恒、四家点数与 Kyotaku 之和恒定、任意时刻合法动作集非空或 Kyoku 已终、回放确定性
- [x] 失败时输出可复现的种子与事件流
- [x] CI 跑规模适中的 soak（局数可配置），FsCheck 与两类对拍全绿
- [x] 此里程碑仍不含 Fable、LLM、UI、脚手架与 Danger
