# 103 — 强 AI 那一行不只说「它打什么」，还说「它有多确定」

**What to build:** 票 93 把「此手强 AI 会怎么打」摆进复盘了，但它只拿得到**一个动作 id**，
于是分歧点只能显示「它打别的」。而**上游那次前向本来就算出了候选分布**——
`probe/akagi-wasm/crate/src/lib.rs` 的 `decision_json` 早就在印
`{"candidates":[{"action":…,"p":…}, …]}`，**是我们自己在跨界那一层把它扔了**
（`Baseline.ask` 只回 `{ ActionId; Failure; LatencyMs }`）。

这一票把那份分布接过来，让复盘里的分歧点从「**它打别的**」变成「**它有多确定**」：
它 0.95 打 3s 而你打了别的，与它 0.38/0.35 两难时你打了它第二候选——**这是两种完全不同的复盘素材**。

**Blocked by:** 无（92 / 93 / 101 / 102 全部集成，站点已上线）

**Status:** ready-for-agent

## 要什么行为

- [ ] `Baseline.ask` / `askAll` 那条口把候选分布带过来（形状你定，但**必须是上游给的那几条**）
- [ ] 复盘那一行（票 93 的 `ReviewStrong`）显示分布：**几条候选 + 各自的概率**
- [ ] **分歧那一栏用得上它**：你打的那一手**在它的候选里排第几、概率多少**——
      「你打的它给了 0.35，排第二」比「你与它不同」有用得多
- [ ] **候选条数由上游给多少定**，不许为了好看截断；真要截断（例如只显示前三）
      **在报告里给出理由**，并把「上游一共给了几条」也带过来
- [ ] 它给不出分布时（老产物、字段缺失）**整行退回票 93 今天的样子**，不是空白、不是「暂无」

## 硬边界：不许编一句人话

**这一票的全部风险就在这里。** 票 92 的判据是「它不会说话：没有 thinking、没有 reason」，
票 93 复述过一遍「别为它编一句」。**概率不是理由**：

- **不许**把 `p=0.95` 渲染成「它很确定该打 3s」「它认为这手危险」之类的句子——
  那是我们替一个不会说话的网络编话，而且**编得越顺口越像真的**
- **可以**写「它给这一手 0.95（候选里第 1）」这类**照抄数字**的说法
- 度量词（「很确定 / 犹豫」）一个都不许出现在页面上；**要不要给阈值分档是产品口味，
  留给人裁**（报告里写提案）

## 必须量的数

- [ ] 带上分布之后**跨界那一层的开销**：payload 大小、解码耗时（票 93 实测逐手 0.72 ms，
      一整局 122 手 87–92 ms——**这一票别把它顶上去**）
- [ ] 候选分布**是不是免费的**：它来自同一次前向，所以推理耗时该**不变**——**量出来证明它没变**，
      别假定（判据 14：说「因为 X 所以慢」之前先量 X）
- [ ] 一整局复盘的总耗时改前改后

## 闸门

- [ ] **分布与上游逐字段对拍**：拿 `probe/akagi-wasm` 那条 node 路径（`run-node.mjs` / `probe.js`）
      对同一份局面问一次，断言页面上那几个概率与 wasm 直接印出来的**逐位相同**
      （**不是**四舍五入之后看着差不多）
- [ ] **概率和**那条不变量：上游给的是 top-k 而不是全分布，所以**和不必是 1**
      ——**先量清楚它到底是什么**，再决定断言什么。**不许**先写一条 `sum = 1` 再去调数据
- [ ] 「排第几」那一栏：构造一个你打了它第二候选的局面，断言那一栏说的是「第 2」
- [ ] 阴性对照：把分布那一段删掉/改坏，闸门要红（判据 1），红的原文进报告；
      **量点停在那一行真的画出来的时刻**（判据 20）
- [ ] 票 92 / 93 的既有闸门一条不少：懒加载（不选它一个字节都不拉）、降级、
      对局中不给复盘、真人那条「结构性不泄露」
- [ ] `./scripts/ci.sh` 全绿

## 顺手记着

**这一票是「我们自己把已经算出来的东西扔了」**，不是「上游没给」。
写报告时把这句写清楚：跨界那一层每加一道窄口，都要问一句
「**上游给了什么、我们扔了什么、扔掉的那部分将来有人要吗**」——
票 92 当时窄成一个 id 是对的（那一票要的就是「它能坐下打牌」），
但那个决定应当在报告里留下一句「分布还在，随时接得回来」，**它没留**，所以这一票要从源码里重新发现它。
