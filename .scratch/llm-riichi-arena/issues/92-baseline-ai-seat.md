# 92 — 强 AI 坐一席

**What to build:** 票 91 探明之后，把那个 WASM 网络接成**第四种选手**：座位能选它，
它与 LLM 席、bot 席、真人席对引擎完全同级（`CONTEXT.md` 的 `Player` 词条：四者同级）。
spec 的 story 35：「让它坐上任意座位作为强度参照系，所以 LLM 的雀力有锚点」。

**Blocked by:** 91

**Status:** ready-for-human

## 要什么行为

- [x] `SeatChoice` 加一支；配桌页选得到；四席怎么混都行（三模型 + 一强 AI、真人 + 强 AI…）
- [x] **懒加载**：首页与普通对局**不拉那几 MB**，选了那一席才拉；拉的时候页面要说话
- [x] **加载失败优雅降级**（story 37 的精神在无后端形态下的翻译）：拉不动 / 跑不起来时，
      页面明说原因，**其余席照常开桌**——它是可选依赖，不是单点
- [x] 它的每一手也进牌谱：`names` 里认得出是它；有没有 `reason` 看它给不给
      （给不出就没有气泡，**别为它编一句**）
- [x] 许可与署名进仓库（票 91 查出来的那几样：LICENSE 片段、NOTICE、来源 commit、体积说明）

## 闸门

- [x] 它坐一席，**打完一局**：终局点数对、牌谱里认得出它、事件流合法
- [x] 降级：把资产地址改坏，断言页面说得出原因且**其余席照常打完一局**
- [x] 懒加载：不选它的那些趟，断言**一个字节都没拉**（网络请求计数）
- [x] 与真人同桌一局（票 87 已在）：断言真人那侧的「结构性不泄露」照旧绿
- [x] CI 里跑不跑真推理**由票 91 的数决定**：跑不动就把它放进「本机演习」那一档，
      **并在报告里写清 CI 因此没覆盖什么**（判据 4：覆盖不到的要写出来）

## 边界

- [x] 不做复盘对照标注（票 93）
- [x] 不碰引擎、不碰 LLM 那条链路（`web/src/agent/**` 只在必须共享形状时碰，且要说明）
- [x] 不改 `CONTEXT.md`（术语若要改名，**由调度器另开授权票**，票 91 出的建议在那儿兑现）
- [x] 不把它塞进首页 Demo 资产

## 要害

**它与 LLM 席最大的不同是「不会说话」**：没有 thinking、没有 reason、没有 token 账单。
现有的气泡、账单行、状态线都要**优雅地什么都不显示**，而不是显示「空」或「0 tok」。
这条最容易在集成时才被发现——**闸门里要有一趟专门断言「它那一席没有气泡、没有账单行」**。
