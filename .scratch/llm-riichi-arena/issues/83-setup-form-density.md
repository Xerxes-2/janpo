# 83 — 配桌表单重排：四席一眼看全

**What to build:** 主人试玩后报的第六条：配桌表单「有点乱且信息密度低」。现在四席纵向堆着，
每席一行选手按钮 + 一个档位下拉 + **两个大文本框**（人格、模板），一屏下去只看得到两席半，
而这一页要回答的是一个很简单的问题：**这四个座位分别是谁、什么档位**。

**Blocked by:** 79（它在翻 `verify-home` 的断言与资产）

**Status:** ready-for-agent

## 要什么行为

- [ ] **四席一眼看全**：座位 → 选手 → 档位 这三样，四行摆在一屏里读得完
- [ ] **人格与模板这两块大文本收起来**（折叠、抽屉、还是弹层由你定），但要满足两条：
      ① 收起时看得出「这一席有没有自定义人格/模板」（有内容要有记号）
      ② 展开一席不许把另外三席顶到屏外
- [ ] **档案库与座位绑定分成两块**：档案库是「怎么问模型」（provider·模型·key·超时·思考），
      座位绑定是「谁坐哪、给多少信息」——它们是两种东西，现在混在一片
- [ ] 那一大段说明文字（`panelNote`）留着但别再占据视线中心：它是查阅用的，不是每次都要读的
- [ ] 纸面牌谱风照旧（票 80 的 CSS 变量，别另起一套颜色）
