# 81 — 视角是一道信息闸门；思考气泡只放一句话

**What to build:** 主人试玩后报的两条。**手牌早就按视角掩蔽了，思考气泡与状态线却没有**——
坐到座位 0 的视角上，照样读得到另外三家在想什么，那句「座位 N 的模型选完了：……」
连理由一起漏。视角因此只是半真的。这一票把**视角**变成与手牌同一条规则的信息闸门；
同时把气泡从「thinking 全文硬裁到 4.2rem」改成**一句话 + 点开看全文**。

**Blocked by:** None（79 已并入）

**Status:** ready-for-human

## 79 并入之后的既成事实（先读这段）

- **首页那份资产已经是真的四席 LLM 对局**（`web/public/demo-paifu.json`，1.12 M 字），
  气泡里是**真理由**：比固件长得多，中位 48 字，最长的几条会溢出。
  79 自己看图时报的那条「**座位 1 的气泡最后一行被面板边缘切掉**」，就是这一票要治的病。
- `verify-home` 第⑦条**已经翻面**：从「一个气泡都没有」变成「末帧四席各一个、每个 ≥8 字、态是 `spoke`」
  （2 条 → 10 条断言）。你改气泡的可见性规则时**这十条要跟着想**：座位视角下四家只剩一家，
  那十条断言必须相应改成「按视角该有几个就有几个」，**不许放宽**。
- `verify-inbound` 里有一条**阳性对照**：无记录的牌谱 → 气泡全没 + 指路话回来。别把它弄成永真。
- 真语料的形状：思考档单手中位 11.7 秒（p95 25.4 秒），直觉档 1.7 秒——
  「在想」那一态在真跑里**会停留很久**，已等秒数那个数字是有人真的会盯着看的。

## 主人的两条裁决（照做）

1. **与手牌同一条规则**：视角 = 座位 N 时，只看得见**那一席**的气泡与状态线；想看全场就切上帝视角。
   回放里也一样（**终局也不放开**——escape hatch 是上帝视角那一按，不是时间）。
2. **气泡只放一句话**：优先显示 `reason`（模型自己给的那句理由），溢出三点号 + 「点开看全文」；
   **thinking 全文是点开之后那块面板的活**（面板早就有了，九行俱全）。

## 既成事实（漏在哪、地基在哪）

- `TableState.bubbles` 取值器只过一道 `unlocked`：
  `not (humanSeated model) || Table.result table |> Option.isSome`
  ——**它一个字都没读 `Viewpoint`**。漏就漏在这儿。
- 那条 `unlocked` 是 ADR-0003 的判据（挂在**对局配置 + 终局状态**上），是 M3 真人坐席的地基，**别动它**。
  这一票加的是**另一根正交的轴**：`视角掩蔽 AND unlocked`，两条都要满足才显示。
- `AgentLine`（票 74 起按座位一份）把多席状态连 `Spoke` 里那句理由一起列出来——同一个漏，同一条规则治。
- 气泡现在 `max-height: 4.2rem; overflow: hidden`（**硬裁且无提示**）；全文面板 `table-bubble-detail` 九行已就位。
- 气泡取值器是唯一数据源（票 76：视图与 17 条用例全读 `TableState.bubbles`）——**改这一个函数，别在视图里再滤一遍**。

## 术语表授权（第八次，范围锁死一条）

- [x] `CONTEXT.md` 的 `Thinking Bubble` 词条现在写的是「展示某个 DecisionRecord 的 **thinking**」，
      与主人刚裁的行为不符。改成：**气泡展示那一手的一句话理由，thinking 全文在点开后的面板里**。
      **只改这一条**，别处一个字不许动。

## 要什么行为

- [x] 座位 N 视角：只有那一席有气泡（其余席**DOM 上没有气泡元素**，不是 CSS 藏起来）；状态线只列那一席
- [x] 上帝视角：四家全开（Live 与回放一致）
- [x] 气泡文字：`reason` 优先；只有 thinking 没有 reason 时取它的头一段并三点号收尾（判据写进注释）
- [x] 溢出有**看得出来的**提示（三点号 + 「点开看全文」之类），不再是硬裁
- [x] 「在想」态（已等秒数与上限，票 74）与「兜底代打」态（朱红 + 原因）照旧
- [x] 危险度那个开关与视角正交，别缠一起

## 闸门

- [x] `verify-bubbles` 加一程：切到座位 N → **只有那一席有气泡元素**、状态线只提那一席；
      切回上帝 → 四家都有。**顺带核那句「模型选完了」的理由不在别席视角里出现**
- [x] 一条阳性对照：上帝视角下四家气泡的文字互不相同（证明不是全都藏了）
- [x] 长文本：拿一份带长 thinking 的记录，断言气泡里是一句话 + 有溢出提示，而面板里是全文
- [x] 每条新断言**先红一次**，红的原始输出抄进报告
