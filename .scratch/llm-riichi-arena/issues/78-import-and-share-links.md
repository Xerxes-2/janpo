## 要什么行为

- [ ] `?table=1` 上一个「复制分享链接」：把这一桌到此刻为止的**棋谱**装进 hash，写进剪贴板，
      并把「这份链接不含推理，完整推理要导出 JSON」说在明处
- [ ] 打开带载荷的地址：直接进回放模式并自动播（与首页 Demo 同一条路径），时间轴可用
- [ ] 「导入牌谱 JSON」：选一个文件 → 回放。全量牌谱带着决策记录，所以**导入的那一份气泡有话**
- [ ] 三种失败各有中文原因、都不许白屏：文件不是 JSON / 牌谱读不动（版本或字段）/ 回放推不下去
      （`ReplayError.toDisplay` 已经把话写好了）
- [ ] 载荷长到某个阈值就**当场提示改用 JSON 文件**（阈值给个数，报告写清依据——票 77 量过东风战与半庄）
- [ ] 分享链接打开的那份没有决策记录 → 气泡不出现（票 76 已经定了这条），页面那句说明要指得回「导入 JSON」

## 闸门

- [ ] **真往返一趟**（浏览器里，不是单测）：`?table=1` 打几手 → 点复制 → 读剪贴板 →
      打开那个地址 → 断言回放出的事件流与原桌逐条相同、点数一致
- [ ] 导入闸门：把导出的那份文件重新导入，断言事件流逐条相同（与 `verify-export` 那道互为反向）
- [ ] 坏输入三连：不是 JSON / 缺字段的牌谱 / 中间某局断掉的事件流，各断言一次「有中文错误且页面还活着」
- [ ] 每条断言先红一次，红的输出进报告

## 边界

- [ ] 不改载荷的形状与编解码（票 77 定的，这一票只调用）
- [ ] 不改 `Paifu` 格式、不碰引擎的规则判定、不碰 `web/src/agent/**`
- [ ] 不做「分享到 X / 微博」这类平台按钮，不做短链服务（**平台没有后端**，ADR-0003）
- [ ] 不做拖拽导入、不做多文件对比复盘（想要另立票）

## 顺手记着

`?dev=1`、`?table=1` 与 hash 三者正交（35-1 与票 71 定的）。分享链接**不带** `?table=1`：
它是给访客看的回放，不该把配桌面板也摆出来。
