# 29a — 掩蔽事件流成为座席的唯一投影，快照降为它的 fold

**What to build:** 把「一个座位能知道什么」这件事**只定义一次**，定义在**事件**上。

现在有两条掩蔽法则：`GameState → Observation`（快照，20 号票）与 prompt 需要的历史（还不存在）。
这一票让掩蔽只发生在事件层，`Observation` 变成**掩蔽流 fold 出来的结果**：

```
改前   GameState ─┬─ mask ─► Observation ─► 牌桌 / 脚手架 / Danger
                 └─ mask ─► 掩蔽事件流 ─► （prompt 想要但还没有）

改后   GameState ─ mask ─► 掩蔽事件流 ─┬─► 座席的历史（29b 的 prompt 前缀）
                                     └─► fold ─► Observation ─► 牌桌 / 脚手架 / Danger
                                                （类型不变，下游一行不改）
```

**为什么**：牌手的读牌建立在「发生过什么、什么顺序、什么**没**发生」之上，快照只能表达「是什么」。
最锋利的例子是**见逃し**——一张牌过了一圈没人碰，这不是一个事件，是一个事件的**缺席**，
它告诉你三家都没有那张的对子。任何快照都表达不了它。同类还有：每张牌是第几巡打的、
立直宣言牌与宣言巡、立直**之后**通过的牌（筋的可靠度天差地别）、第几巡碰了什么鸣完打了什么、
杠宝牌何时翻开、九种九牌等途中宣言。我们此前一条条给快照补字段（28 号票原本要补两项），
补的是症状。

**Blocked by:** 28

**Status:** ready-for-agent

## 一、掩蔽定义在事件上

- [ ] 掩蔽函数：一条事件 + 一个座位 → 该座位可见的那条事件（或不可见）。他家摸牌隐去牌面、
      暗杠隐去牌面、配牌只见自家。判据与 `MaskedSeat` 同源
- [ ] **属性测试（不泄露）**：任意对局任意座位，掩蔽流里不出现他家暗牌中的任何一张
- [ ] 上帝视角对应的未掩蔽流也要有（围观与 M2 复盘要用）

## 二、`Observation` 改为 fold 派生（expand–contract）

- [ ] **expand**：新增 `fold(掩蔽流) → Observation`，与直算实现并存
- [ ] **迁移闸门**：属性测试断言两种实现**逐字段相等**（这条测试是一次性的迁移工具，不是长期资产）
- [ ] **contract**：确认相等后**删掉直算 `GameState` 那套**，闸门测试随之退役或改成回归守卫。
      终局只剩一条掩蔽法则
- [ ] `Observation` **类型不变** → 24 的 `Scaffold.calculate`、25 的 `Danger`、22 的牌桌**一行都不用改**。
      如果发现必须改它们，说明这一票的做法跑偏了，停下来记 DECISIONS
- [ ] fold 的代价要看得见：牌桌是逐步推进的，**别每帧重头 fold 全流**（增量维护或缓存；
      牌桌本来就在 fold 事件，接上去就行）

## 三、历史里必须能读出来的东西（29b 会用，这一票负责有）

- [ ] 每条打牌的巡目与跨家先后；手切摸切**及其时序**（标记本来就有，缺的是时间轴）
- [ ] 河与鸣的时序对齐：哪张牌在第几巡被谁鸣走、鸣完打了什么
- [ ] 立直宣言牌与宣言巡目；立直之后通过的牌
- [ ] 见逃し：一张牌过了谁都没要——由「打牌事件后没有鸣牌事件」推得，不必单独造事件
- [ ] 杠宝牌的揭示时机；九种九牌等途中宣言

## 四、顺带钉两条规则蕴含的不变量

- [ ] 立直成立之后该家的打牌必须**全是摸切**（立直宣言牌本身除外，它通常是手切）
- [ ] 碰 / 吃之后的那张打牌必然是**手切**（鸣牌没有摸牌动作）；杠之后是岭上摸牌，允许摸切
- [ ] 违反即说明事件生成有 bug——属性测试钉住

## 五、边界

- [ ] **不碰 prompt**。prompt 的翻转、缓存、牌谱只存尾部全在 29b
- [ ] 牌桌 UI 除了「接上 fold」之外不改外观；宣言牌横置等显示归 M2 的布局票
