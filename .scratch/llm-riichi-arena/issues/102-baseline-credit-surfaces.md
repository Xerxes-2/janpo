# 102 — 把强 AI 基线的来历摆到人看得见的地方（页面 + README）

**What to build:** 主人的要求：**在网页和 README 里说明这个强 AI 基线是什么、来自哪里。**

今天的账：`web/public/third-party/README.md` 那份声明**写得很全**（上游 / 来源 commit / 许可 /
静态链进来的那几个库 / 权重语料查不到那条风险），页脚也有一条链接指过去。缺的是两件：

1. **页面上不点名**：页脚只说「强 AI 基线那份产物含第三方 Apache-2.0 代码与内嵌权重」，
   而**用户在配桌页拨到那一席、在牌桌上等它加载**的时候，看不到它是什么、是谁做的。
   署名要落在人**遇到它**的那一刻，不是只落在一个要点开才看得见的页面里。
2. **README 那一节已经过时且事实错误**：`## 现在能玩到什么，还差什么` 里写着
   「**还差**：本地真人也坐一席；接一个成熟的麻将 AI 做对照基线」——
   **这两件 M3 都做完了**（票 87/88/89 与 92/93）。README 是给外人看的唯一真源，它现在在说假话。

**Blocked by:** 无（M3 全部集成，站点已上线）

**Status:** ready-for-human

## 术语纪律（先读这条，别写错名字）

主人第九次术语授权定了：**概念一律用通名「强 AI 基线」**，
**具名（Akagi 的 `native_bot`）只出现在署名 / 说明 / 报告里**。
这一票要写的正是那些「署名与说明」的地方，所以**具名在这里是对的**；
但**`CONTEXT.md` 与 `spec.md` 一个字都不许改**，README 里讲概念的地方也照旧用通名。

事实以 `web/public/third-party/README.md` 与 `probe/akagi-wasm/NOTICE-upstream.md` 为准，
**不许自己另写一份来源描述**（两处措辞不一致就是下一个 bug）。要点：
上游 [shinkuan/Akagi](https://github.com/shinkuan/Akagi) 的 `native_bot/`、来源 commit `394b3290`、
Apache-2.0、纯 Rust 的 CNN（candle 推理，行为克隆自人类天凤牌谱）、
**权重的具体语料上游未公开、我们无从核**。

## 要什么行为

### 页面

- [x] **在人拨到那一席的地方就说得清它是什么**：配桌页那一席被选中时（或它的说明处）
      写出「它是什么 + 谁做的 + 什么许可 + 一条通往第三方声明的路」。
      **一句话量级，别写成论文**——页面其余部分的语感是「只说访客关心的那几件事」（票 37 的判断）。
- [x] **加载那一刻也认得出它**：今天拉那 6 MB 时页面会说话（票 92 的 `Loading` 态），
      那句话里该出现它的名字。
- [x] **降级那句话不许变味**：拉不动时今天说的是原因 + 退回自带 bot，
      那句话已经在生产环境里被主人读到过一次，**语义不许退化**（可以加名字，不许变成一句机器话）。
- [x] 页脚那条既有的第三方声明链接**保留**（Apache-2.0 §4(d) 的义务落在它身上）。
      **它不许挂在「选了那一席才显示」后面**——`Footer.fs` 里那条判断写着理由，别破。

### README

- [x] 新增一小节讲**强 AI 基线是什么、来自哪里**（通名做标题，具名与来源写在正文；
      许可与权重那条风险要提，一句话 + 链到站点上那份声明或仓库里的 `NOTICE-upstream.md`）
- [x] **把 `## 现在能玩到什么，还差什么` 与主线现状逐条核对**：
      「还差」里那两条**已经做完了**，别只加不减。M3 落地的东西：
      真人坐一席（出牌 + 吃碰杠立直荣和自摸 + 信息辅助 + 思考时限）、
      脚手架三档齐（裸奔 / 信息辅助 / 工具搜索）、复盘逐手对照标注（引擎自算的量 + 强 AI 那一行）、
      强 AI 基线坐一席（懒加载、拉不动就降级）。
      **核对方式不是凭记忆**：`.scratch/llm-riichi-arena/run/reports/8[7-9]*.md`、`9[0-3]*.md` 逐份看结论。
- [x] 「还差」那几条写**真的还差的**（例如：它永远不给理由；三档的对照实验还没人跑；
      没有联机与天梯）——**别把没做的事说成做了，也别把做了的事继续挂在「还差」里**

## 顺手记着

**README 那句「还差：接一个成熟的麻将 AI 做对照基线」是这个项目最典型的一类错**：
记录声称了一件事，而那件事的执行体早就不是那个状态了。
判据 3 讲的是断言空转，这一条是**文档空转**——它同样只能靠「拿现状去核那句话」发现。
写完这一票，README 里每一句「现在/还差」都该有一份报告能背书。
