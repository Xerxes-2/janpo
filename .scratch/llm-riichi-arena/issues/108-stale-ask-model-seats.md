# 108 — 模型席那条路上的「过期问话」：一份在飞的问话会拿旧包落子

**What to build:** 票 92 修了强 AI 那条路的过期问话（`drain` 顶上按
「引擎此刻给这一席的合法动作集与包里那一列逐条相同」剪一遍 `Consulting`），
**并明说同一族的问题在模型席那条路上也存在**（`live.Awaiting` 没有这道剪枝），
只描述、不编号，留给调度器。就是这一票。

**为什么它比清理更急**：响应阶段可能在别席答完之后**当场散掉**（有人碰了），
那一席的待答整条消失，而它那份在飞的问话还留着——**包里的 id 是按旧的合法动作集编的号**。
`Awaiting` 那一侧今天没有剪枝，于是那份回执回来时，**同一个 id 指的是另一条动作**。
引擎会拒（`DecisionPackage.tryAction` 拿不到就没有事情发生），
但在那之前 `waiting` 为真、牌桌停着——**要么打错、要么卡住，两条都不能接受**。

**Blocked by:** 无

**Status:** ready-for-human

## 要害：过期的问话已经花掉钱了

这一票最容易做错的地方**不是剪枝，是剪掉之后的账**：

- [x] **token 不许从账上消失**：那次问话真的调了 provider、真的计了费。剪掉它之后，
      账单行里那几个数**该是花掉的总额**—— `Table.usage` = 决策记录 + `Table.Voided`
      （修前量到的是：引擎拒掉那一条之后记录整条被丢，**814 tok 当场从账上消失**）
- [x] **但它不许留下一条声称落了子的 `DecisionRecord`**：那一手没有发生。
      「花了钱、没落子」是真实情形，记录要说得出这件事 —— `VoidedAsk`（票号 / 手序 / 座位 / 原因 / 账单）
- [x] 那一席**要被重新问**，而重问不许把上一轮的历史丢掉（票 95 的 `prefix.test.ts`）
      —— 用例钉的是「新那一票**落得下去**」；`web/src/agent/**` 一个字节都没碰
- [x] 剪枝不许把**还在当下**的问话误剪（阴性对照）—— **80 场 / 336 局 / 28,916 手
      / 124 轮多席同问 → 剪枝 0 次**（量点停在那一场真的打完之后，判据 20）
