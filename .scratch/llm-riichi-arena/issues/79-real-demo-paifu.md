## 要什么行为

- [ ] 四席全是模型，**四个不同的人格**（例如防守型 / 进攻型 / 爱鸣牌 / 中庸），
      同一份 `ModelProfile`（`deepseek-v4-flash`）——这正是票 73 说的对照形态
- [ ] 跑**东风战**；跑几场挑一场（判据写在报告里：有立直、有副露、以和了终、最好有顺位变化）
- [ ] 换掉票 71 那份占位资产，按它报告里写的手续走
- [ ] 首屏体积把住：资产带着 thinking 会胖（实测约 10 KB/手）。量出实际字节与首屏加载耗时；
      过大就换成一局、或降思考预算，**别把首页拖死**

## 报告里必须有的数（M2 的第一份真实语料账）

- [ ] 墙钟：一局多久、一场多久；并发问话省下多少（与票 74 用假端点量的那两个数对照）
- [ ] 账单：`Usage` 累加（付全价输入 / 命中缓存 / 输出），缓存命中率，一场大约多少 token
- [ ] 兜底手数与原因分布；有没有 429 / 超时（四席并发对同一个 provider 是新形态）
- [ ] 气泡的**等待感**：一手要等多久才有话可看。这条决定「气泡要不要做成流式」
      （26-11 提过，票 76 明确留给这次实测定；**结论写进 `DECISIONS.md`，要么立票要么判不做**）
- [ ] 模型打得怎么样的第一手观感（不必量化）：会不会立直、会不会乱鸣、有没有明显蠢手——
      spec 说「裸 LLM 的低段位表现本身是内容」，这是第一份素材
