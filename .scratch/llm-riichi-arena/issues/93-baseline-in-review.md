# 93 — 强 AI 的对照标注进复盘

**What to build:** spec 的 story 36：「在复盘面板中看到『此手强 AI 会怎么打』的对照标注，
所以分歧点成为复盘素材」。票 90 已经把复盘的骨架与引擎自算的量做好了，
这一票在**同一栏**里加一行：它会打什么。

**Blocked by:** 90, 92

**Status:** ready-for-agent

## 要什么行为

- [ ] 终局后，真人（以及模型席）的每一手旁边多一行：**〔强 AI〕打 X**
- [ ] **分歧点要跳出来**：你打的与它打的不同的那些手，在时间轴上看得出来（一眼扫得到分歧在哪几手）
- [ ] 它是**事后重算**的：拿那一手当时的**该席观测投影**去问它——
      **不许拿上帝视角去问**（那会给出一个人类做不到的答案，对照就没意义了）
- [ ] 它没坐这一桌时也能算（复盘时才加载），**算不动就整行不出现**（别显示「暂无」）
- [ ] 算一整局要多久要给数；太慢就做成「点某一手才算那一手」

## 闸门

- [ ] 一局打完，断言分歧手数 ≥ 0 且**每一条对照都能复现**（同一手问两遍给同一答案，
      或它本身带随机性时把这条写清楚并改断言）
- [ ] **投影正确**：构造一个「上帝视角会打 A、该席视角只能打 B」的局面，断言标注给的是 B
      （这是这一票唯一真正难的断言，**先红一次**要拿「故意喂上帝视角」来红）
- [ ] 它不可用时：断言复盘照常出（只是没有那一行），票 90 的断言一条不少
- [ ] 票 87 的「结构性不泄露」在**对局中**照旧绿——复盘是终局后的事

## 边界

- [ ] 不改票 90 立的那几栏（向听/有效牌/危险度）
- [ ] 不造总分、不造「你比它差多少」的评分
- [ ] 不碰引擎、不碰对局中的任何路径
- [ ] 不做「让它替你打完剩下的」这类接管功能

## 要害

**「拿哪一份观测去问它」是这一票的全部难点。** 复盘时全局状态都在手上，随手一喂就是上帝视角，
而那样的对照毫无意义（它知道你不知道的牌）。
判据：**喂给它的必须与那一手当时喂给该席的是同一份投影**——
引擎的 `Observation.ofState` 已经是纯函数，用它，别自己拼。
