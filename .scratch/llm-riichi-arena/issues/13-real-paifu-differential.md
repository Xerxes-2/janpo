# 13 — 真实牌谱对拍

**What to build:** 用真实牌谱检验符点与役种的长尾：把天凤/雀魂格式转成 mjai 事件流，再以牌谱里的动作序列驱动引擎，对拍每次和了的役种集合、符、点数与终局点数。**样本量优先、可增量**——首批样本先小，参数化扩大，不把牌谱获取变成阻塞里程碑的硬墙。

现成的牌谱转换实现基本都在 Python 生态，允许用 uv 直接跑（`uv run --with <pkg>`）作为**构建/测试期的外部工具**；它不得成为引擎或 CLI 的运行时依赖。

**Blocked by:** 08, 09, 11

**Status:** ready-for-agent

- [ ] 转换器把外部牌谱格式转为 mjai 事件流；无法转换的样本被显式跳过并计数，不静默丢弃
- [ ] 批量重放：以牌谱的动作序列驱动引擎，对拍役种集合、符、点数与终局点数
- [ ] 差异以可读形式报告：哪一局、第几手、期望与实际分别是什么
- [ ] 首批样本量下差异为 0
- [ ] 样本量与牌谱来源可通过参数扩大，不需改代码
- [ ] 已知不支持的规则变体（三麻、地方规则、古役）在跳过时标注原因
- [ ] 牌谱与外部工具的获取步骤写进 README，可从零复现
