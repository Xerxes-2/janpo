**What to build:** 票 117 立起固定舞台之后，方牌桌嵌在 16:10 的框里，
**两侧各剩 272 px（合计 45% 的舞台宽）**。主人报：「两边大片空白有些别扭」。

那两片不是「空白」，是**没分配**——信息辅助、危险度图例、复盘本来就得有地方住，
而它们的家正是这两列。主人已点头「配置部分可以做成可弹出的菜单」（票 116）
与「气泡我准许你覆盖其他元素」（这一票）。

**两列分工**：

| | 对局中 | 终局后 |
|---|---|---|
| **左列 = 谁在打** | 名册（四席全名 + 立直记号）+ 危险度图例 | 名册 + **复盘导航** |
| **右列 = 这一手怎么看** | 信息辅助（向听 / 有效牌 / 现物 / 无筋） | **当手全文** |

**Blocked by:** 117

## 主人在这一票里撤掉了一条不变量

原话：**「气泡我准许你覆盖其他元素，只需要气泡可以随时点击收起或者展开，
收起状态就只有小气泡，里面是 thinking… 之类的就行」。**

这等于撤掉 `verify-bubbles` 那条**「气泡不与牌排 / 中央相交」**。
**覆盖率不许凭空消失**——拿这三条顶上来（原型均已实测）：

| 撤 | 顶上来 | 原型实测 |
|---|---|---|
| 气泡不与牌排 / 中央相交 | ① **收起态** × 牌 = 0（常驻的不许压牌） | 0 ✓ |
| | ② 点得开**且**点得收（四席各走一个来回，两个方向都真点） | 4/4 ✓ |
| | ③ **收起态尺寸有上限**（是「小气泡」不是卡片） | 47×28 ✓ |

**③ 不能省。** 没有上限，「收起」可以退化成什么都不收，而 ①② 照样全绿——判据 60 那个坑。

## 调度器已定（主人可否决）

- **覆盖权用在展开态，不用在收起态**。收起态是**常驻**的，让一枚常驻小气泡永久压着一张牌是白占
  （原型 v2 就这么坏的：上家那枚正压在手牌列上）。
  收起态 = 名册行尾那一个字（`说` / `想…` + 角标），**不占牌桌一寸**；
  展开态 = 从名册点开的**浮层**，浮在牌桌上（实测展开态 × 牌 = 6，这是**要的**）。
- **浮层一次只开一枚**。名册相邻两行只差 26 px 而浮层高 ~45 px，
  先让它红一次：同时开相邻两席**实测互相压 = 1**。改成一次一枚后 = 0。
  这同时治信息过载——四枚同时浮在牌桌上没人读得完。
- **浮层的 top 由代码对齐到它那一行名册**。写成固定槽位时尾巴差 40–60 px 指在空处。
- **复盘只能画在「终局 + 座位视角」那一屏**（见下，硬约束）。
- 四色相纪律内（票 80）：危险度四档用靛蓝 · 墨 · 朱红三相分，**没动第五个色相**。

## 硬约束：`ReviewShown` 三态

`src/Janpo.Web/Review.fs`：

- `Hidden` —— **未终局：复盘整块不在 DOM 里**（对局中给「换打会怎样」算作弊）
- `Unaddressed` —— 终局但上帝视角：只说一句「切到某一席就看得了」
- `Notes of seat * notes` —— 终局 + 某一席：逐手标注

∴ **review 那一屏顶条选中的必须是「座位 N」而不是「上帝视角」**，
且对局中那一屏**不许出现复盘**。原型的截图 C 是按这条摆的。

**文案逐句抄 `Review.fs` 的渲染出口**（`ReviewNote.headline` / `figures` / `advice`、
`ReviewStrong.toDisplay`、`ReviewFilter.toDisplay` / `toggle`、`Review.worth`、
「回到原处（正在看第 N 手）」），**不自造**。

## 列宽是最长的真实模型名定的，不是拍的

原型报出「最坏余量」之后才看见：`deepseek/deepseek-v4-flash` **需要 159.2 px、有 159 px**
——差 **0.2 px**。那不是「放得下」，是**巧合**。拿五个真实长名字量了一遍：

| 名字 | 12 px / 列宽 244 | 11 px / 列宽 256 |
|---|---|---|
| `deepseek/deepseek-v4-flash` | 余 11.8 px | 余 37.0 px |
| `anthropic/claude-sonnet-4-5` | 余 10.4 px | 余 35.7 px |
| `google/gemini-2.5-flash-preview` | **截** | 余 16.6 px |
| `openai/gpt-4.1-mini-2025-04-14` | **截** | 余 20.5 px |
| `qwen/qwen2.5-72b-instruct` | 余 16.0 px | 余 40.9 px |

∴ 列宽 256 + 名字 11 px。**不许靠去掉 provider 前缀缩字**：
票 82 的 nameplate 形状必须匹配 `/^[^/\s]+\/[^/\s]+$/`，改它要单票授权。
腾出那 43 px 的办法是**整行本身就是开气泡的按钮**，行尾不再另摆一枚 pill。
