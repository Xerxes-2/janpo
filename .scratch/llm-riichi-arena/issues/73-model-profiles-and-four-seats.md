# 73 — `ModelProfile`（模型档案）+ 四个座位各自选选手

**What to build:** 现在页面只有**一席**能交给模型（`TableModel` 里 `LlmAt: Seat option` + `Llm: LlmSeat`
各一份），而 spec 的 M2 第一块就是**四 LLM 同桌**。主人裁定的形态是**命名档案库 + 座位引用**：
先建几份命名的**模型档案**（怎么问一个模型：provider·模型·key·baseUrl·超时·思考预算），
四个座位各自选「均匀随机 / 有主见 / 某份档案」，并各自带自己的**脚手架档位·人格·prompt 模板**。
这样「同一个模型跑两种人格」「同一把 key 坐三席」都不必把 key 填四遍。
