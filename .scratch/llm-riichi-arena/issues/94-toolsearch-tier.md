# 94 — 脚手架第三档：ToolSearch（单步 what-if 查询工具）

**What to build:** `ScaffoldTier` 三档里的最后一档。`CONTEXT.md` 已经写死了它的判据：
「**ToolSearch 加的是自己去问的能力，不是又一批算好的数值**，因此不落在『感知 vs 计算』这条判据的两端上」。
主人裁定的形态：**单步 what-if** —— 模型可以问「假如我打 X，向听 / 有效牌 / 危险度变成多少」。

**Blocked by:** None（与真人那条线不交叉；但**与票 95 都碰 `web/src/agent/**`，别同波**）

**Status:** ready-for-human

## 要什么行为

- [x] 座位选 ToolSearch 档时，prompt 里多一个可调用的工具：
      `what_if(discard)` → `{ shanten, ukeire, danger }`（字段名与形状你定，但**必须是引擎已有的量**）
      —— 落成 `what_if(action_id)`：**接头处是 id 不是牌**（赤 5 与正 5、手切与摸切各是一条动作）；
      答案就是引擎 `Scaffold.calculate` 算的那三样
- [x] 工具的答案**与 Assisted 档给的是同一个函数算的**（不许为工具另算一遍）
      —— `trial` 与 `dangerLine` 原样，两档同一个 id 的那一行**逐字节相同**（1,296 行逐条断言）
- [x] 模型可以问**多次**（不同的牌），要有**上限**（防止一手问三十次把账单打穿）；上限值要给理由
      —— `WHAT_IF_LIMIT = 4`，理由三条（手牌张数 / 账单 / 延迟）在 `what-if.ts` 的文件头
- [x] 问过的每一次都**进决策记录**（`DecisionPackage` / `DecisionRecord` 里那一格今天叫 `Tools`），
      这样气泡点开之后看得见它查了什么、查了几次——**这正是这一档的可观测性**
      —— 落在那一手的 `PromptTail` 里（气泡的「prompt 尾部」那一格），`Tools` 那一格多一份
      `what_if` 的 schema；**没有新增任何 F# 字段**
- [x] Assisted 与 ToolSearch 的**可缓存前缀不许分叉**（`CONTEXT.md`：档位只动得了尾部）
      —— 分叉**恰好是那一段工具说明**：剪掉它之后与 Assisted 的前缀逐字节相同（断言 + 两个阴性对照）

## 必须量的数

- [x] 多轮往返对**延迟**的乘数（对比 Assisted 档：票 79 实测直觉档单手中位 1.7 s）
      —— 单手中位 **5,970 ms（×3.4）**、p95 17,052 ms；一场东风战 48.7 分钟
- [x] 对**账单**的乘数（票 79：缓存命中 45%；工具往返会不会把命中率打下去，要量）
      —— **命中率不降反升：36% → 73%**；请求 ×3.67、总输入 tok ×3.1、
      **付全价输入只 ×1.31**、**输出 tok ×6.0**
- [x] 模型**实际问几次**（中位与 p95）——它可能一次都不问，那本身就是发现
      —— **中位 4、p95 4（上限就是 4）**：给过工具的 309 手里 302 手真去问，只有 7 手一次没问。
      **「它一次都不问」被否掉了，而且上限是紧的**

## 闸门

- [x] 假端点上：模型发起工具调用 → 拿到答案 → 出牌，整条链路走通，决策记录里三样都在
      —— 浏览器第十六趟 `verify-toolsearch.mjs`（真的一条 `what_if` SSE tool call 过 pi-ai 适配器）
- [x] 工具的答案与 dotnet 侧同一个函数**逐字段对拍**
      —— 第三道对拍 `scaffold-crosscheck.ts`，真语料上 **42,621 个字段**，配 3 个反向自证
- [x] 上限：让假端点无限发问，断言到上限就停且**这一手照常打完**（不许卡死）
      —— `--what-if inf` 那一席恒是「查 4 次、0 兜底、照常出牌」；把上限那一行拆掉当场卡死（阴性对照 D）
- [x] Bare / Assisted 两档**一个字都没变**（对照实验的自变量只许有一个）
      —— 144 份渲染的摘要 `21bab6bf`，**这个数是动手之前从 `@-` 那一版渲染器上算出来的**
- [x] 真跑一局（真 key，不进 CI）：把上面三组数抄进报告
      —— 种子 15、392 手 5 局、1,448 次请求、**0 兜底 0 次 429**

## 边界

- [x] 不做多步搜索、不做「模拟到终局」——**单步 what-if**，主人裁的
      —— `what_if` 只收一条打牌 id，答的是打完那一瞬，没有任何递归
- [x] 不给真人做查询面板（真人那侧是票 89 的 Assisted 档）
- [x] 不碰引擎的算法、不碰真人坐席那条线
      —— `src/Janpo.Engine/**` 零改动；`src/Janpo.Web/**` 只动了 `Agent.fs` 的两行注释
- [x] 不改 prompt 的记法与战略目标（票 95 在做，**两票别同波**）
      —— 模板哈希 `6f98e9a9` 一个字符没变，只有渲染器摘要跟着换
