# 42 — 随机选手要有一点倾向性，否则立直与供托路径永远跑不到

**What to build:** 现在的随机选手是**均匀随机**：27 号验收实测，**2000 个种子里只有 15 场出现过立直**。
于是立直、供托结转、振听、一发、里宝牌这些路径在验收与回归里**根本不发生**——
代码有、测试有、但真跑一整场碰不到。给随机选手加一点最起码的倾向性，让这些路径在正常对局里真的出现。

**Blocked by:** None — can start immediately.

**Status:** ready-for-human

**做完了**：报告 `.scratch/llm-riichi-arena/run/reports/42-opinionated-random-players.md`，
决策 `DECISIONS.md` 的「## 42」。一句话：立直成立的场次 **15 → 1996**（同样 1..2000 号种子）。

## 要做什么

- [x] 新增一种**有倾向的**选手（别改掉现有的均匀随机选手：它是黄金用例与确定性对拍的基准，
      **改了会让 40 条黄金用例全部失效**）
      —— `src/Janpo.Engine/OpinionatedPlayer.fs`，**另起一份文件**；`RandomPlayer.fs` / `Kyoku.fs` 未编辑

      它不是要变强，是要让规则路径发生
      —— 三条硬规则（`wanted`），其余仍是按权重取样；鸣牌只判到「这一组本身就是役」为止
- [x] 给出实测：同样扫 2000 个种子，立直场次从 15 涨到多少；一发、里宝牌、供托结转、

## 边界

- [x] **不碰均匀随机选手的行为**，一个字节都不许改
      —— `RandomPlayer.fs` / `Kyoku.fs` 不在 diff 里；牌桌均匀那一档仍指 `Kyoku.randomPlayer` 本尊
- [x] 不做 AI 强度（Mortal 基线是 M3）—— 不看点数、不看危险度、不看形好坏
- [x] 不碰 prompt 与 Agent 层 —— `src/Janpo.Web/Agent.fs` 与 `web/src/agent/` 一行未动

## 为什么它是 M2 的前置

M2 要四家 LLM 同桌。**没有立直就没有真正的对抗**——危险度、振听、一发、供托这些
让麻将成为麻将的东西全都不出现，四家 LLM 打出来的对局会是一场平淡的自摸竞赛，
既看不出脚手架差异，也验不到规则路径。
