# 12 — 四类特殊流局

**What to build:** 四类非荒牌的 Ryuukyoku：四风连打、四杠散了、九种九牌、四家立直。每类的触发条件、结算方式与 Honba / Kyotaku 处理都不同。

**Blocked by:** 05, 09, 11

**Status:** ready-for-agent

- [ ] 四风连打：首巡四家打出同一风牌且期间无 Naki
- [ ] 四杠散了：第四个杠成立后触发；单人四杠不流局的情形处理正确
- [ ] 九种九牌：首巡无 Naki 时进入合法动作集，由 Player 宣言
- [ ] 四家立直：第四家立直成立后触发
- [ ] 四类流局均不授受听牌料；Honba 递增与 Kyotaku 结转正确；连庄判定正确
- [ ] 黄金用例：每类流局各一条，四杠散了另加单人四杠的反例
