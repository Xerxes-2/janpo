# 12 — 流局的其余全部形态

**What to build:** 把 Ryuukyoku 的剩余形态补齐。04 已做荒牌流局与听牌料，本票补：四类途中流局、三家和了、以及 **Nagashi Mangan（流し満貫）**。做完这一票，「一局能怎么结束」这个问题在引擎里就没有缺口了。

**Blocked by:** 05, 09, 11

**Status:** ready-for-agent

- [ ] 四风连打：首巡四家打同一风牌且无 Naki
- [ ] 四杠散了：第四个杠成立后流局；单人四杠不流局
- [ ] 九种九牌：首巡无 Naki 时进入合法动作集，由座位宣言
- [ ] 四家立直
- [ ] **三家和了**：作为规则集字段——天凤为途中流局，雀魂为三响成立不流局（证据见 DECISIONS 提案 S-A）
- [ ] **Nagashi Mangan**：牌山耗尽时，若某家全部 Dahai 均为幺九牌且从未被鸣走（10 票记录的标记），以满贯清算**替代**听牌料清算；Oya 听牌则连庄
- [ ] 各形态的 Honba 与 Kyotaku 处理正确；途中流局不授受听牌料
- [ ] 属性：任何形态结束后四家点数与 Kyotaku 之和不变
- [ ] 黄金用例：每种形态各一条；Nagashi Mangan 额外一条「河里有被鸣走的牌因此不成立」

**注意**：Nagashi Mangan 与三家和了是调研牌谱来源时发现 spec 漏掉的——天凤与雀魂**都有** Nagashi Mangan，若不做，13 票的对拍会在这类局上无差别失败。
