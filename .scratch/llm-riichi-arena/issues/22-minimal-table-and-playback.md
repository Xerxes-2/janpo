# 22 — 最小牌桌与播放控制

**What to build:** 把 19 号票那个「打印终局点数」的页面换成真正的牌桌：四家的手牌数、河、副露、
宝牌指示牌、点数、场风与自风、本场与供托，随事件逐步出现。围观者能暂停、单步、加速，能开上帝视角
看任意一家的完整手牌。四家仍然是随机 Player —— 这一票不碰 LLM，只要「能像看牌谱一样看完一个 Kyoku」。

**Blocked by:** 19

**Status:** ready-for-human

- [x] **UI 状态 = fold(事件前缀)**，不存在第二份游戏状态（ADR-0002 的直接后果）
- [x] 一步一 Msg 推进：Elmish 的 update 就是驱动循环，不另写一个 loop
- [x] 渲染项齐全：各家手牌（他家默认背面）、河（手切与摸切可区分）、副露（含杠的形态）、
      宝牌指示牌、点数、场风/自风、本场、供托、剩余摸牌数、立直棒
- [x] 播放控制：暂停 / 单步 / 加速（倍速或步进间隔），随时可切
- [x] 上帝视角开关：打开后能看任意一家的暗牌；关掉后 DOM 里也不该留着他家的牌
- [x] 和了与流局有可读的结算显示：役种、番符、点数授受、听牌家、连庄与否
- [x] 能从头到尾看完一个 Kyoku，中途不卡、不报错
- [x] DOM 渲染，不用 Canvas；**第一版无动画**，纯状态跳变（spec 的动画预算后置）

**术语纪律**：界面上的中文一律照 `CONTEXT.md`；牌面的人类可读形式只存在于渲染层，事件流里仍是 mjai 记法。
