# 80 — 前端美化：纸面牌谱风（静态打磨 + CC0 牌面资产 + 配色）

**What to build:** 访客与主人看到的每一屏在同一套「纸面牌谱」视觉语言下：米白纸底、暖墨字、
朱红与靛青两个各司其职的强调色；**牌看起来是牌**（CC0 SVG 牌面嵌进统一的象牙白圆角牌框），
座位视角的他家暗牌是**牌背**而不是斜纹方块；思考气泡像页边批注。**功能一行不改。**
M1 一路的判据是「CSS 不许过夜」（功能票不许顺手打磨），欠的账全在这一票还。

**Blocked by:** 74（等待秒数那一态）、78（分享/导入入口）——它们正往界面上加新部件，美化要一起罩住。

**Status:** ready-for-agent

## 主人的三条裁决（照做，别自由发挥）

1. **只做静态。** 动效（补间动画）、移动端重排、暗色模式都**没选=不做**（spec 的「动画预算后置」照旧）。
   hover/focus 的即时状态变化可以，会动的东西不行。
2. **北极星是纸面牌谱风**：围棋书·棋谱·研究室的气质。**不是**雀魂绿毡，**不是**电竞暗色。
3. **资产与配色**：
   - 牌面用 **FluffyStuff `riichi-mahjong-tiles`**（github.com/FluffyStuff/riichi-mahjong-tiles）：
     **CC0 公共领域**（调度器核过 LICENSE 与内容清单）、SVG、含 **Man5/Pin5/Sou5-Dora 三张赤五**与
     **Back 牌背**。用 `Regular/` 那套；要调色走 CSS。
   - 配色主调（色值是锚点，实现者调、主人看图终审）：米白纸底 ≈`#f6f1e7`、暖墨 ≈`#2e2a24`、
     **朱红** = 赤牌·立直·兜底警示、**靛青** = 链接·选中·时间轴。气泡淡纸灰底 + 左墨线，像批注。
     配色落成 **CSS 变量**（一处定义），正文与牌面字对比度至少 WCAG AA。

## 要什么样子

- [ ] **牌**：手牌 / 河 / 副露 / 宝牌指示牌全换 SVG 牌面 + 统一牌框；赤五用 `-Dora` 变体且与普通五
      **一眼可分**；暗牌用 `Back`；**语义记号一个不丢**——横放（副露来源）、刚摸那张的间隔、
      摸切虚线、立直标签、危险度色阶
- [ ] **牌的身份仍要机器可读**：牌面变图之后，每张牌是什么必须还留在 DOM 上（`data-*` 或
      `aria-label`，形态你定）。闸门从「读文本」改「读身份属性」时**断言一条不许放宽**
- [ ] **每一屏都罩住**：首页回放、`?table=1`（配桌三开关 + 档案库 + 四席绑定 + 对局）、气泡三态与
      全文面板、结算面板（役与符番）、危险度、两层错误提示（「载荷读不动」「牌谱读不动」）、
      `table-no-bubbles` 那句、导入与分享入口、页脚
- [ ] **资产管线**：SVG 进仓库（CC0 不需署名，但 README 与报告记来源与 commit）；sprite 或按需引由你定；
      **不加运行时依赖、不加 webfont**（本地字体栈）
