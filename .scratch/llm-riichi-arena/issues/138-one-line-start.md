# 138 — 开桌的第一步：从七步压到一步

**What to build:** 配桌那一块最上面一行 `provider · 模型 · key · 〔开打〕`，按下就开出一桌；
并把「key 只在这台浏览器」那句话摆到 key 那一格旁边。评审 P1-E。

**Status:** ready-for-agent

## 现状（我核过的）

- 最短路径确实长：`自己开一桌` → 配桌 → 新建档案 → provider → 模型 → key → 把某席拨给档案 → 播放。
- **key 那一格旁边没有任何一句说明**（`TablePanel.profileEditor`，`table-profile-key`）。
  「只写进这台浏览器的 localStorage、请求由浏览器直接发给 provider」这句今天写在
  README、文档、和配桌那个「这几格都是什么意思？」折叠里——**需要它的那一秒它不在**。
- 配桌那一块自票 126–130 起是横跨整框的顶栏（不再是 116 那个抽屉），
  **票面里说的「抽屉最上面一行」按今天的形状读作「配桌那一块最上面一行」**。

## 要什么行为

- [ ] 配桌最上面一行：provider（下拉）· 模型（自由文本）· key（password）·〔开打〕
- [ ] 〔开打〕= 建一份匿名档案 → 绑座位 0 → 其余三席留 bot → 直接播
- [ ] 人格 / 模板 / 脚手架 / 超时 / 思考预算全部收进「进阶」，默认收起
