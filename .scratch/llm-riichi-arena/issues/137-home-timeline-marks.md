# 137 — 首页不该停在第 1 手

**What to build:** 首页时间轴带上记号、落点放到第一个「值得看的」那一手、分享链接带手数。评审 P1-D。

**Status:** ready-for-agent

## 我量到的那条真因（票面里最要紧的一段）

稿子说「首页却只给局号」。**接线其实早就有了**：`TablePage.layout` 把 `review.Marks`
一并交给 `TablePanel.ops`，首页与主持人页走的是同一条。真正的原因在别处——

`Review.marks` ← `Review.focused` ← `Review.notes` ← `Review.addressed`，
而 `addressed` 在**上帝视角下恒是 None**（「复盘的第一个字是『你』，四家一起复盘不是票 90 的东西」）。
首页默认就是上帝视角 ⇒ **`Marks` 恒是空表**，轴上那几枚从来没有出现过一次。

∴ 这一票不是「把记号接上去」，是**给首页一批不需要主语的记号**。

## 现成的、不需要主语的三种记号

它们都是**牌谱里的事实**，不是对某一席的建议，因此上帝视角下照样成立：

| 记号 | 判据 | 出处 |
|---|---|---|
| 兜底 | `DecisionRecord.Fallback <> None` | `Paifu.Decisions` |
| 重试 | `Attempts > 1` | 同上 |
| 格式跑偏 | 重试原因里那一类（`Attempts > 1` 且原因是解析失败） | 同上 |

**模型出丑那几手是这个产品最有说服力的内容**，而今天它们只在状态行里被数了个数。

## 要什么行为

- [ ] 三种新记号出现在时间轴上，**四家通用、不挑视角**；每种记号形状可辨（不是三枚一样的点）
- [ ] 它们与既有的「值得看的那几手」**同一次投影出来**（同 `ReviewView` 那条「一处算、两处消费」），
      不许另开一条算路
- [ ] 首页落地位置 = **第一个有记号的那一帧**，不再是第 1 手；一枚记号都没有时才退回第 1 手
- [ ] 首页顶上一句可点的话——「它为什么打这张？」——按下去坐进那一席（走既有的 `RecordOpened`）
- [ ] 分享链接带手数：转发出去的是一个瞬间。**载荷格式不许改**（票 77 的 `stripAudit` 一个字不动），
      手数走 URL 里另一个参数
- [ ] 首页那次多算的 marks 是**纯函数**：牌谱已终局，不碰 `Playback` 世代号

## 从票 143 转过来的一条硬要求（不是建议）

票 143 量出来：**首页那 58 字的终局复盘指路话，到那一票为止从未被任何闸门数到过**
（⑬ 从前不等牌桌画出来就量，量到的是 loading 那一帧）。它是新口径下首页最长的一段散文，
而**首页那条上限 125 就是为容下它才定的**。

它与这一票要加的那句可点的「它为什么打这张？」**说的是同一件事的两半**——
一个是「打完之后去哪看」，一个是「现在这一手看什么」。∴ 这一票必须：

- [ ] **把这两句合成一句**（或让新的那句吃掉旧的那句的活），首页不许同时挂着两句指路话
- [ ] 合完之后**把首页那条上限从 125 收下来**（143 的报告说该收到 70 上下，**你自己重量一遍再定**）
- [ ] **不许靠抬上限过关**：这一票只减不增

## 边界

- [ ] **不改 `Review.addressed` 的语义**（票 90 的地盘）：上帝视角仍旧没有「换打会怎样」
- [ ] 不改分享载荷编解码（票 77/78 的地盘），不涨 `Paifu.Version`
- [ ] 不动首页那两句文案（票 120 刚砍过）
- [ ] 不动引擎
