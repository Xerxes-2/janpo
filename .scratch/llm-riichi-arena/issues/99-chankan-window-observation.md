# 99 — 抢杠那个窗口：观测 fold 与引擎分了家（回放会显示一个从未成立的杠）

**What to build:** 票 98 摊出两座抢杠牌山之后，逐字段对拍捅出一个**真 bug**，
不是测试的事：**`kakan` 事件一播出去，掩蔽流 fold 出来的观测就把那组碰原地升成了杠、
把那张牌从手里拿走；而引擎要等杠成立才动**（宣言不改局面，被抢时无需回滚）。
**被抢之后那个杠永远不成立，观测那份再也没回滚。**

`Observation` 是掩蔽事件流的 fold（票 29a），**座席看到的历史、浏览器里的回放、
Agent 收到的观测走的都是它**。真牌谱语料里抢杠 **22 局**——一旦回放到那一局，
牌桌上会显示一个**从未成立的杠**，而那一手的手牌数也少一张。

**Blocked by:** 无（98 已集成，两座牌山与探针都在仓库里）

**Status:** ready-for-agent

## 术语那一件：只出建议，不许自己改

国士抢暗杠时那四张牌**必须**亮给别家看（不然没法决定抢不抢），而它们在引擎里仍是暗牌，
于是「掩蔽流里不出现他家暗牌」这条不变量**在那个窗口里本来就不成立**。

**这要的是把「宣言中的暗杠」在术语上认成公开信息，不是把断言调松。**
`CONTEXT.md` 的 `Observation` / `MaskedEvent` 词条**你一个字都不许改**：
写一段建议（措辞 + 影响到哪几条不变量 + 哪几处代码），**由调度器与主人处置**。
