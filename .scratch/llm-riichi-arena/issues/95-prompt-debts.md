## 债一：prompt 里混着三套记法

现在同一份 prompt 里「打 3s」「discard 3索」「打三索」都出现过——模型要在三套记法之间翻译，
而它出错的时候我们只看得到「它打错了」。

- [x] **全走 mjai 记法**，一套到底（`3s` / `5mr` 那一套，与事件流、动作 id、牌谱同源）
- [x] 给人看的中文仍在 UI 那一侧（ADR-0001：wire 数据不带渲染出口）——**这一票只动 prompt**
- [x] 语义不变量那一趟（`verify-invariants`，11 条 + 14 个反向自证）要跟着核：
      **不许放宽**，该改的是断言里的记法而不是强度

## 债二：从没告诉模型「顺位比点数重要」

- [x] preamble 里加一句战略目标：**整场顺位是目标，单局点数不是**
      （四麻的基本常识，而我们从来没说过）
- [x] 它落在**可缓存前缀**里（整场一份），不是每手重发——别把它塞进尾部
- [x] 与「人格」分开：人格是风格（防守型/进攻型），这一条是**规则常识**，四席都该有

## 必须量的对比（两条债一起量）

- [x] **渲染版本号会变**（`render_version`）：改前改后各跑一局，把两份 preamble 贴进报告
- [x] 缓存命中率：改后是否仍在 45% 上下（前缀变长了，第一手更贵、后面更省，**要给数**）
- [x] 兜底率、单手延迟：与 79 的基线对比
- [x] **打法有没有变**：同一颗种子、同一份档案，改前改后各跑一局，
      看立直/副露/和了的次数——**这是「战略目标那句话有没有用」的唯一证据**
