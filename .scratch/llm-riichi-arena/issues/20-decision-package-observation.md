# 20 — 决策包：Observation 投影与编号动作集

**What to build:** 引擎多出一个能力：给定局面与某座位的合法动作集，产出**那个座位能合法看到的一切** ——
它自己的手牌与副露、各家的河（含手切/摸切）、宝牌指示牌、点数、场风自风、本场供托、巡目、剩余摸牌数、
各家立直状态、自己的振听状态 —— 外加**带 id 与中文 label 的动作列表**。这就是「决策包」：LLM 与
（M3 的）真人坐席消费的唯一输入，两边共用同一个投影，隐藏信息的保护因此在结构上成立而不靠纪律。

反方向只有一个整数：给决策包和一个 id，取回那个 `Action`。**`GameState` 永不越过边界，TS 侧永不构造
`Action`** —— 非法输出因此在结构上不可能，这是 M1 接缝的核心决策。

**Blocked by:** None — can start immediately.（纯引擎票，与 19 号并行，不碰 Fable）

**Status:** ready-for-agent

- [ ] Observation 投影是纯函数：局面 + 座位 → 该座位的合法观测；**类型里根本没有他家暗牌的位置**
- [ ] 属性测试：任意局面任意座位，投影的序列化结果里不出现他家手牌中的任何一张牌
- [ ] 上帝视角是**独立**投影（含全部暗牌），与合法观测各走各的类型，不是一个带 flag 的开关
- [ ] 动作列表每项带：稳定的 id、mjai 风格的结构化字段、**中文 label**（渲染层单向出口，ADR-0001）
- [ ] id → Action 的取回；id 越界或不存在时返回 None 而不是异常（兜底路径要它）
- [ ] 决策包有单向 encoder（F# → JSON），字段命名沿用 mjai wire 的习惯；不需要 decoder
- [ ] CLI 能打印某座位的决策包 JSON，肉眼可查
- [ ] 脚手架数值**不在这一票**：Shanten / Ukeire / 进退向由 24 号票加进决策包，Danger 由 25 号票加。
      这一票只把槽位留好，别把它们塞进来

**边界提醒**：投影是「分析附件」之外的东西 —— 它不做任何规则判定，也不算任何数值，只做**遮蔽**。
