票 44 把牌桌改成三×三格子就是为了给它留锚点。

## 要什么行为

- [x] 每席一个气泡，三种态一眼分得开：**在想**（正在等这一席的回执）/ **说了什么**
      （thinking 优先，没有思考预算时退回那一句理由）/ **兜底代打**（原因，粘着不掉直到它又能好好说话）
      —— `Bubble` 三个 case + `data-bubble` + 三种画法（虚线 / 实线 / 红），取值器是
      `TableState.bubbles : TableModel -> Table -> (Seat -> Bubble option)`（报告 §1）
- [x] 气泡点得开：全文面板给出 thinking 全文、那一句理由、prompt 尾部、动作 id 集、
      最终落定的动作、延迟、问了几次、Usage、渲染版本
      —— `table-bubble-detail` 九行（`bubble-*` 各一个 testId）；「最终落定的动作」取自快照那一帧的
      `Latest`（牌谱里只有包内 id，26-3）
- [x] **Live 与回放两边都要**：回放沿游标取那一手的记录；Live 里点历史某一手同样展开
      （story 5：连当时的局面快照一起，走票 75 的前缀 fold，**只读，不影响推进**）
      —— Live 走「`Table.paifu` → `Table.replay` → 取那一帧」，**不常驻帧数组**，实测点一下
      6–62 ms（报告 §4）；用例钉着 `live.Table` 的事件流逐条相同
- [x] 牌谱里没有决策记录时（bot 席、或分享链接那种棋谱）**不出气泡**，页面上一句话说清为什么
      （`table-no-bubbles`；判据是**整份牌谱**没有记录而不是这一帧没有，否则那句话会在开局闪一下）
- [x] 气泡不许挡住牌与河：牌桌八项（票 44 的闸门）一项都不能被压住
      —— 气泡是座位面板里的一行、不做绝对定位；闸门读**真坐标**：与四家的三排牌 / 牌桌中央
      矩形不相交，且画在那一席的框里（红-12 / 红-13）
- [x] 可见性判据挂在**对局配置与终局状态**上，不挂在「用户是谁」上（ADR-0003 的 consequence；
      真人坐席那条「终局前隐藏」是 M3，本票只要把判据放在对的位置，别做成 M3 要重写的形状）
      —— `unlocked model table = not (humanSeated model) || 终局`，`humanSeated` 恒 false 且是
      **代码里的一个值**（判据 4）；跑得到的那条断言是「五个视角下气泡逐个相同」

## 闸门

- [x] 假端点跑几手：断言气泡里的字**来自那一手的决策记录**（改记录 → 气泡跟着变）

      一字不差出现在气泡里；dotnet 侧另有「改一个字，气泡跟着变」一条
