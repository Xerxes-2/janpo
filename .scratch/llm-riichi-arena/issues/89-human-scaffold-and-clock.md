# 89 — 真人的信息辅助与思考时限

**What to build:** 两件座位级配置，都是 spec 明写的：

- **story 33**：「作为新手真人玩家，我想选配与 LLM 同款的信息辅助（向听/有效牌/危险度提示），
  所以脚手架机制同时是我的新手辅助轮」——**`ScaffoldTier` 复用到真人席**（`CONTEXT.md` 词条最后一句已经写了）
- **story 32**：「我想选配思考时限（默认不限时），所以我可以按自己的节奏打，也可以模拟竞技压力」

**Blocked by:** 87

**Status:** ready-for-human

## 要什么行为

- [x] 真人席也能选脚手架档位（票 73 的座位配置里那一格，今天只对模型席生效）
- [x] **Bare**：什么都不给（与模型的 Bare 同一条判据：「一个坐在牌桌前的人免费得到的一切」，
      `CONTEXT.md` 那条「感知 vs 计算」的线**逐字照用**，别自己发明清单）
- [x] **Assisted**：向听、有效牌（张数与是哪些）、危险度排序——**与模型看到的是同一份数**
      （同一个引擎函数，不许为 UI 另算一遍）
- [x] **ToolSearch**：这一票**不做**（票 94），选到它时按 Assisted 处理并说明
- [x] **思考时限**：座位级，默认不限时；设了就倒计时，**超时自动摸切**（响应阶段自动过）
- [x] 倒计时要看得见，且**只在轮到自己时走**

## 闸门

- [x] **Bare 的阴性对照**：真人席设 Bare，对局中断言页面上**没有任何向听/有效牌/危险度的数字**
      （这条比正面断言重要——辅助轮漏出来就是作弊）
- [x] Assisted：断言那几个数**与引擎算的逐字相同**（拿 dotnet 侧同一个函数对拍）
- [x] 时限：设一个很短的时限，不动手，断言到点真的自动打了（且打的是**摸切**那一张）
- [x] 时限设「不限」时：等足够久，断言什么都不会自动发生

## 边界

- [x] 不做 ToolSearch（票 94）、不做复盘（票 90）
- [x] 不碰引擎里 Shanten / Ukeire / Danger 的算法，只是把它们**摆到真人这一侧**
- [x] 不改模型席的脚手架行为（对照实验的自变量不许动）
- [x] 不做「暂停/续下」这类对局控制

## 要害

**同一份数**这条要落成代码事实而不是纪律：真人看到的向听与模型 prompt 里的向听
**必须来自同一次调用或同一个纯函数**。两处各算一遍，迟早有一天对不上，而那时你会先怀疑引擎。
