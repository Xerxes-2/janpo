# 90 — 复盘：逐手对照标注

**What to build:** spec 的 story 34：「终局后得到针对我每一手的复盘，所以这个平台也是我的练习工具」。
主人裁定（M3 起草时）：**引擎自算的量打底，强 AI 可用时再叠加**（票 93）——
所以这一票**零外部依赖**，终局后立刻有东西看。

**Blocked by:** 87

**Status:** ready-for-agent

## 对照物长什么样（主人选的形态）

```
第 7 手  你打 3索
  向听 2 → 2      有效牌 33 → 21（−12）
  换打 8筒：有效牌 39（+6）、危险度更低
  〔强 AI〕……（票 93 接入后才有这一行）
```

判据：**每一条都是引擎已经会算的量**（`Shanten` / `Ukeire` / `Danger`），
不是新发明的评分。**不要造「这一手打得几分」这种总分**——那需要一个模型，而它是票 93 的事。

## 要什么行为

- [ ] 终局之后，真人那一席的**每一手**都有一条标注：向听怎么变、有效牌怎么变、危险度多少
- [ ] 「换打某张会怎样」：至少给出**比你打的那张更好的几个候选**（按有效牌或危险度排），
      没有更好的就明说「这一手是当时的最优之一」
- [ ] 挂在**已有的时间轴上**（票 75/86 的游标）：点某一手就跳到那一刻，
      **不许另起一条时间轴**（ADR-0002 那条：轴只有一根）
- [ ] 只在**终局后**出现（对局中给出「换打会怎样」就是作弊——它属于 Assisted 档，见票 89）
- [ ] 模型席也能看（复盘不是真人专属），但**真人在座的那一局，对局中一律不给**

## 闸门

- [ ] 打完一局，断言真人每一手都有标注，且那几个数**与引擎直接算的逐字相同**
- [ ] **对局中没有**：中途断言复盘面板不在 DOM 里（阴性对照）
- [ ] 「更好的候选」那一栏：构造一个明显打错的局面（有效牌少一大截），断言它真的把更好的那张列了出来
- [ ] 点某一手 → 游标跳过去 → 关掉回原处（票 86 立的回程规矩，别破）

## 边界

- [ ] 不接强 AI（票 93）；那一行**留出位置但不占位**（没有就整行不出现，别显示「暂无」）
- [ ] 不碰引擎的算法；不造新的评分体系
- [ ] 不碰对局中的信息辅助（票 89）
- [ ] 不做「导出复盘报告」这类新产物——复盘读的是牌谱，牌谱已经能导出能分享

## 顺手记着

这一票让**牌谱里那些决策记录第一次对真人也有用**：模型席的 `reason` 与真人席的这些标注
排在同一条时间轴上，就是「它为什么那样打 / 我为什么这样打」的并排。
