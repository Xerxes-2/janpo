# 50 — 罕见流局形态没有闸门守着，因为跑批的选手到不了

**What to build:** `Soak.rare` 里那几种形态（四家立直、四杠散了、三家和了……）**不在必覆盖名单里**，
因为 CI 跑批用的覆盖型偏好选手**到不了**——`Soak.rare` 的注释写着四家立直在 1500 场 7536 局里
一次都没出现。于是这些规则路径**长期没有任何闸门守着**：代码有、测试有，跑批碰不到。

票 42 的有主见选手 500 场 2542 局跑出了 **3 次 `ryukyoku:suchareach`**（决策 42-8）。
它当时没动 `Soak.required`——因为闸门跑的仍是覆盖型选手，挪进去会红。**这一票把两者接起来。**

**Blocked by:** None（票 42 已落地）

**Status:** ready-for-human

## 要做什么

- [x] 判断每一种 `rare` 形态**归谁覆盖**：覆盖型偏好选手到得了的，进 `required`；
      只有有主见选手到得了的（立直相关的那几种），**由一道用有主见选手的跑批来守**
- [x] CI 加一道（或扩一道）跑批：用有主见的选手，**要求**那几种立直相关形态出现。
      场数取到「稳定出现」为止，并给出实测频率作为依据（**别拍一个数字**）
- [x] 仍然到不了的形态（四杠散了这类），**如实写清「谁也到不了、因此仍无闸门」**，
      别把它们混在 required 里假装有覆盖
- [x] `Soak.rare` 那段注释按新事实重写（现在它记的是「覆盖型选手 1500 场没碰到」，
      而事实已经变成「换个选手 500 场碰到 3 次」）
- [x] **CI 时间不许失控**：给出这道新跑批的耗时；超过一分钟就减场数或改成抽样，
      别减形态。（现有 `./scripts/ci.sh` 约 1 分钟，这是本地开发的手感底线）

## 边界

- [x] **不碰覆盖型偏好选手与均匀随机选手的行为**（它们是黄金用例与双目标对拍的基准）
- [x] **不碰 `scripts/ci-web.sh`**（票 49 正在改它一行）；`scripts/ci.sh` 可以改，但只加你这一道
- [x] `src/Janpo.Cli/Program.fs` 若要动，**改动尽量集中**——票 49 可能也要动它（给 `decide` 加选手开关）
- [x] 不碰 prompt、Agent 层、牌桌

## 为什么这票值得做

与票 49 同源：**闸门的语料决定闸门有没有牙。** 本项目已经写进规矩的判据是
「一道从不失败的闸门等于没有闸门」，票 41/49 又补了一句「**它在真语料上执行过几次？**」。
`Soak.rare` 是这条判据在引擎侧的同一个洞：名单在那里，**没有任何一次跑批能让它开口**。
