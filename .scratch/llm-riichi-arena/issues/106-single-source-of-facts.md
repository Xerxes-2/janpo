## 三件

1. **闸门趟数只许有一处真源**：今天 `scripts/ci-web.sh` 有两处总述（注释 + `echo`）、
   `web/scripts/verify-setup.mjs` 文件头还写着「十一趟」（**现在十八趟**，票 87 报告的 nitpick 3
   记过、票 76 与 81 也各记过一次）。**做法自己定**（从列表现算最自然），
   但判据是：**加一趟闸门时，没有任何一处「几趟」需要手改**。
2. **产物路径写在五处**（票 101 报告 ⑩ 的 Duplicated Code）：跨 TS / YAML / bash 三种文件。
   **能收几处收几处**，收不动的（例如 YAML 里那处）**写明为什么收不动**（判据 4）。
3. **`ci.sh` 里没有许可闸门**（票 101 报告 §留给人 1）：今天谁删掉 `web/public/third-party/`
   都不会红——只有 Pages 那条**不常跑**的路上的 `check-pages-dist.sh` 会。
   **Apache-2.0 §4 的义务不该挂在一条不常跑的路上。** 往 `ci-web.sh` 加一道。
