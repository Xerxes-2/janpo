# 106 — 同一事实写在多处：闸门趟数、产物路径，以及一条挂在不常跑的路上的许可闸门

**What to build:** 三件同族的事，都是「**同一个事实写在好几处，于是它们各自漂**」。
调度器在 M3 集成时被第一件**撞红过三次**（票 92、90、89 各加一趟闸门，每次两侧都改同一行总述）。

**Blocked by:** 无（但**别与正在加闸门的票同波**——它改的正是「加闸门」这条路）

**Status:** ready-for-agent

## 三件

1. **闸门趟数只许有一处真源**：今天 `scripts/ci-web.sh` 有两处总述（注释 + `echo`）、
   `web/scripts/verify-setup.mjs` 文件头还写着「十一趟」（**现在十八趟**，票 87 报告的 nitpick 3
   记过、票 76 与 81 也各记过一次）。**做法自己定**（从列表现算最自然），
   但判据是：**加一趟闸门时，没有任何一处「几趟」需要手改**。
2. **产物路径写在五处**（票 101 报告 ⑩ 的 Duplicated Code）：跨 TS / YAML / bash 三种文件。
   **能收几处收几处**，收不动的（例如 YAML 里那处）**写明为什么收不动**（判据 4）。
3. **`ci.sh` 里没有许可闸门**（票 101 报告 §留给人 1）：今天谁删掉 `web/public/third-party/`
   都不会红——只有 Pages 那条**不常跑**的路上的 `check-pages-dist.sh` 会。
   **Apache-2.0 §4 的义务不该挂在一条不常跑的路上。** 往 `ci-web.sh` 加一道。

4. **闸门自己印的那个 `✓` 不看结果**（调度器 2026-08-19 撞见）：
   我把候选概率轻轻舍到三位小数去撬票 103 的「逐位对拍」，闸门**正确地 exit 1 并逐条印出两边的数**
   （`页面 0.765 / wasm 0.7653265`），**但同一次跑批的叙述行仍然印着**
   「页面上那几个概率与 wasm 直接印的严格相等 **✓**（其中 **0** 个连字面都一样）」
   ——那些 `✓` 是**写死在字符串里、在收集完 `missing` 之后无条件打印**的
   （`verify-review.mjs:1277` 那一处，而 `grep -c ✓ web/scripts/verify-*.mjs` 显示十几条闸门都是这个形状）。
   **它不影响退出码，但它让日志不能读**：这个仓库已经栽过「假红比真红危险」（判据 16），
   而「印着 ✓ 的那一行其实刚失败」是同一族里更阴的一种——**没人会去查一条打了勾的行**。
   - [ ] 做法自己定（最省的：那一行的 `✓` 由该项自己的成败决定，失败就印 `✗` 或干脆不印那一行）
   - [ ] **不许**只改 `verify-review.mjs` 一处：这个形状是从 `browser-lane.mjs` 的约定长出来的，
         要么统一改掉，要么写明为什么只改一处（判据 4）
   - [ ] 顺手核一件：那一行里的计数（上面那个 `0 个连字面都一样`）在失败时是**真的**——
         数是对的、只有那个勾是假的。别把数也一起改坏
