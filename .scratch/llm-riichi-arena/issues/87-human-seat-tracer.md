# 87 — 真人坐下，把一局打完（M3 的曳光弹）

**What to build:** 主人自己坐上一个座位，与三个模型（或 bot）同桌，**把一局打完**。
这一票只做「出牌」这一条最窄的路：点自己手里的一张打出去；轮到别人时看着；
**鸣牌一律自动过**（吃碰杠立直荣和是票 88）。它要立起来的是 M3 的整根骨架——
**真人是第四种选手，引擎与编排层不区分它与 AI**（spec 的 story 28、30）。

**Blocked by:** None

**Status:** ready-for-human

## 地基已经在了（别重造）

- `CONTEXT.md` 有 **`Human Seat`** 词条：「由本地真人操作的 Player 实现，其决策函数渲染动作输入 UI 并等待交互」
- `TableState.humanSeated` **今天恒 `false`**（票 76 埋的桩）；`unlocked = not humanSeated || 终局`
  是 ADR-0003 立的可见性判据，**票 81 已经把它与 `reveals`（视角掩蔽）AND 起来了**。
  你把 `humanSeated` 变成真的，**气泡自动在终局前消失、终局后解锁**——那条路一行都不用改。
- 观测投影是引擎一等能力（`Observation.ofState`）：**真人 UI 与 LLM prompt 用同一份投影**，
  隐藏信息的保护「在结构上而非纪律上成立」（spec 的架构决策）。
- 座位绑定是 `SeatChoice`（`Bot kind | Profile name`，票 73）——**加第三支**。

## 要什么行为

- [x] 配桌页某一席能选「我自己」；四席可以三模型一真人，也可以真人 + 三 bot
- [x] 轮到真人打牌时：**点自己手里的一张就打出去**。哪些牌能点由**引擎给的合法动作集**决定
      （spec：合法性驱动 UI，**不许 UI 自己判**）——摸切与手切都要能表达
- [x] 轮到别人时真人只看着；**真人在想的时候整桌等着**（不限时，时限是票 89）
- [x] 响应阶段（有人打牌、真人能鸣）**一律自动过**，且**页面要说出来**它替你过了什么
      （否则人会以为平台漏了）——票 88 会把它换成真按钮
- [x] `humanSeated` 变成真的：对局中视角锁死自家（上帝视角与别席视角**在 DOM 上不可达**，
      不是灰掉），终局后解锁
- [x] **堵掉 22-A**：`?dev=1` 那页的曳光弹在 DOM 里印四家配牌。真人在座时**不许开**
      （挂账 22-A 从 M1 记到现在，受害者今天才出现）

## 闸门

- [x] 无头脚本坐一席，**把一局打完**（点手牌→打出→等三家→再点），断言终局点数四家和为定值
- [x] **结构性不泄露**（story 29）：对局中把整页 HTML 抓下来，断言**他家的手牌一张都不在里面**
      （连 `data-*` 都不许有）——这是 M3 最重要的一条断言，**先红一次**要用「故意把投影换成上帝视角」来红
- [x] 对局中：上帝视角与别席视角的按钮**不在 DOM 里**；终局后它们回来
- [x] 真人在座时开 `?dev=1`：曳光弹不给开（阴性对照：没有真人时照旧能开）
- [x] 气泡：对局中一个都没有（`humanSeated` 生效），终局后四家的都回来

## 边界

- [x] 不做吃/碰/杠/立直/荣和/自摸（票 88）、不做时限（票 89）、不做信息辅助（票 89）、不做复盘（票 90）
- [x] 不碰引擎的规则判定与 `Observation` 的投影逻辑（**要的都已经有了**）
- [x] 不动 `reveals` / `unlocked` 的规则本身，只让 `humanSeated` 说真话
- [x] 不碰 `Paifu` 格式：真人的动作与 bot 的动作在牌谱里同级，**不加新字段**
- [x] 不碰 Mortal / 强 AI（票 91–92）

## 顺手记着

牌谱里怎么写真人？`Roster.names` 今天是 `provider/model` 或 `random`。真人席写什么由你定，
但**要能与模型席区分**（复盘与分享都要读它），且**不许写进 key 之类的私人信息**。
