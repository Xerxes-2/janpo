# 136 — 对局中的右轨：让主角上台

**What to build:** 右轨在**对局中**常驻「刚落子那一席」的推理全文 + 三个元数字。评审 P0-C。

**Status:** ready-for-agent

## 现状（评审那份稿子的说法已经过期，按这一段写）

稿子写「118 的报告自己记着：右轨对局中是空的」。**今天不是空的，但仍缺这一票要的东西**：

- 票 123 之后右轨 = `TableBoard.statusRail` + `ReviewPanel.ReviewView.Panel`（`TablePage.layout`）。
- `statusRail` 对局中在（轮到谁 / 四席在做什么 / 上一手 / 账单 / 记分板四行）。
- `Panel` **对局中恒空**：`Review.settled` 为假时 `ReviewShown.Hidden`，整块不在 DOM 里。
  那条规矩是票 90 立的、有理由的（对局中给「换打会怎样」＝作弊），**这一票不许推翻它**。

∴ 缺的**不是复盘**，是**它当时说的那段话**——今天只缩在名册行尾一枚药丸里（`ThinkingBubble`），
要点一下才展得开。而「它在想什么」是这个产品最值得看的东西。

## 要什么行为

- [ ] 右轨在 `statusRail` 下面多一块：**刚落子那一席**的推理全文（`DecisionRecord.Reason` /
      `Thinking`，与气泡浮层同源，不许第二份判据）
- [ ] 三个元数字接在下面：延迟（`LatencyMs`）· 重试（`Attempts - 1`）· tok（`Usage`）
- [ ] 播放时**自动跟随**刚落子那一席；单步 / 点开某一手时**钉住**那一手
- [ ] 其余三席仍旧是药丸（气泡那套一个字不动）
- [ ] **兜底那一手在这里写足原因**（`Fallback` 那句中文），不再只在状态行里数个数
- [ ] 纵向上限 + 块内滚动：**不许推动 `--board`**。今天牌宽 = `--board * 0.0468`，
      右轨把 `--board` 挤小一点点，四家的牌就一起变小——闸门要有一条
      「右轨塞进一段超长推理前后，`--board` 与牌宽逐像素不变」
- [ ] 视角那条老规矩照旧：`TableState.reveals` 说这一席看不得，就一个字都不出

## 边界

- [ ] **不动 `Review.settled` / `ReviewShown` 三态**（票 90 的地盘）：复盘仍旧只在终局之后
- [ ] 不动气泡的收起 / 展开语义（票 118）
- [ ] 不动 `styles.css` 里 `--board` / `--tile-w` 的算法（那是票 139 的地盘）
- [ ] 不动引擎、不动牌谱格式
