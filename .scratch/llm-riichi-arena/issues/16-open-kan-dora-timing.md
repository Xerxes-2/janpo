# 16 — 明杠的新宝牌翻开时机（13 票对拍发现的真 bug）

**What to build:** 修正明杠（Daiminkan / Kakan）的新宝牌指示牌翻开时机。当前实现在杠成立时立刻翻，天凤是**打牌那一刻才翻**；暗杠才是立刻翻。这是一个**会算错点数**的 bug。

**Blocked by:** None — can start immediately

**Status:** ready-for-human

## 证据（13 票的对拍，别重新调研）

- **218 局真实牌谱实证**：暗杠立刻翻、明杠等打牌那一刻才翻。加杠后**当场岭上开花**的局，牌谱里根本没有 `dora` 事件——而我们多翻了一张
- 影响 **2/2110 kyoku**，其中一局把 **40符2飜(2700) 算成了满贯(8000)**
- 详见 `run/reports/13-real-paifu-differential.md` 与 `DECISIONS.md` 的提案 13-B
- 11 票当初的实现照的是固件 18/18 的事件顺序，那批样本里没有「明杠 + 岭上开花」的组合，所以没暴露

## 为什么 13 票没顺手修

改法要给 `GameState` 加状态（记住「有一次明杠的新宝牌待翻」），**并且要改 `KanTests` 两条既有断言的期望值**——那是 11 票的断言，13 票按 RUNBOOK 不自作主张改别票的断言。本票明确授权改。
