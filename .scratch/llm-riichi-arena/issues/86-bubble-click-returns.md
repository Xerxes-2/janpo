# 86 — 点开气泡跳走了，关掉却不跳回来

**What to build:** 主人试玩时报的：「气泡的点击是不是有问题，为什么会动时间轴」。

查过代码：**跳是有意的**（票 76 的 `openAt`，注释写着「轴只有票 75 那一根，全文面板不另开一条时间轴；
于是牌桌自己就是那一手的快照，两边只有一份渲染」）——这个理由站得住，**别推翻它**。

**漏的是回程**：`RecordOpened None`（关掉面板）只做 `Opened = None`，**游标留在跳过去的那一处**。
于是「读一条理由」变成了「时间轴被搬走」：看完关掉，轴停在别处，再按播放从那儿继续。
上帝视角下四家气泡各指着各自最后一手，点谁都往回跳一段，更晕。

**Blocked by:** None

**Status:** ready-for-human

## 要什么行为

- [x] **点开记住原处，关掉回到原处**：关面板（`bubble-close`）之后游标与播放状态回到点开之前那一刻
      （`Opened.Origin = { Cursor; Playing }`；回程走 `returned` → `Playback.resumed`，在播就续上一记定时器）
- [x] **按「播放」也算关**（今天任何推进牌桌的消息都会收起面板）：那时同样要先回原处再继续播，
      **不许从跳过去的地方接着播**（`moves` 那条路走 `rewound`：**只搬游标**，播放状态让那条消息说了算，
      理由与取舍见报告 §3 与 DECISIONS 86-2）
- [x] **面板上说出来它跳到哪了**：摊开时明写「正在看第 N 手」（今天只有 `data-bubble-turn` 给机器看，
      人看不见自己被搬到了哪儿）——新 testId `bubble-viewing`，回放与 Live 两句话
      （判据在 `BubbleDetail.toDisplay`；Live 那一句不提时间轴——那一页根本没有）
- [x] Live 那一侧本来就没有游标（`openAt` 只摆快照、`live.Table` 一字不动），**行为不许变**
      （那一侧**根本不记原处**，`RecordOpened None` 与票 86 之前逐字相同）
- [x] 「一点就暂停」保留（票 76 的判据：牌桌上摆着快照时定时器推得再快人也看不见）
      （`openAt` 的 `Playback.pause` 一字未动；另立一条「点开之前暂停着，收起来还是暂停着」钉着）

## 闸门

- [x] 回放里：记下游标 → 点开某家气泡（断言游标真的挪了、面板真的开了）→ 关掉 →
      **断言游标逐字回到原处**，且播放状态与点开之前相同
      （`关掉全文面板：游标与「在播不在播」一起回到点开之前那一处`：11 → 9 → 11，在播跟着回来，
      **过期世代的定时器仍旧作废、当前世代的推得动**；另两条盯「暂停着点开」与「摊着时拨倍速」）
- [x] 同一条路走「按播放」而不是「按关闭」：断言也回到原处再往下播
      （`按「播放」也算关`：收了面板、回 11、在播，**下一帧是 12 而不是 10**；
      另一条 `拖时间轴与从头再放` 钉着回程不许把人刚拖到的那一帧顶掉）
- [x] 连点两家气泡再关：断言回到**最初**那一处（不是上一次跳的地方）
      （`连点两家气泡再关`：11 → 9 → 8 之后，「收起」与「按播放」两条路都回 11）
- [x] Live 那一侧：点开 / 关掉前后 `live.Table` 与推进能力（`canAdvance`）逐项不变
      （`Live 那一侧一字不变`：手数 / 事件流 / 决策记录 / `canAdvance` / 播放状态在三个时刻逐项相同）
- [x] 每条先红一次，红的原始输出抄进报告（报告 §5：**十次**，dotnet 八次 + 浏览器两次）

## 边界

- [x] **不推翻「点开跳到那一手」这条设计**（票 76 的理由仍然成立：一根轴、一份渲染）
      （`openAt` 的去程一个字没改，只多了一句「把挑走的两样东西记下来」）
- [x] 不动 `reveals` / `unlocked`（票 81 立的两根轴，M3 的地基）
- [x] 不动气泡的文字判据与 72 字上限（票 81 刚量出来的）
- [x] 不碰引擎、`Paifu`、`web/src/agent/**`、`web/public/demo-paifu.json`
- [x] 不碰牌桌几何与页面块次序（票 82 正在动，**它若已并入就以 `main` 为准**）
      （`TableBoard.fs` / `TablePage.fs` / `TablePanel.fs` / `styles.css` 一字未动）
- [x] testId 只许增（只增了 `bubble-viewing`，没改名、没删）

## 顺手记着

这条挂账的形状值得记：**票 76 把「跳过去」写进了注释与实现，却没人问「怎么回来」**——
一个动作只做了一半，而两边的用例各自都绿（点开有快照 ✓、关掉面板没了 ✓）。
**闸门要成对地想：状态被改了，就要有一条断言管「改回来」。**
