# 86 — 点开气泡跳走了，关掉却不跳回来

**What to build:** 主人试玩时报的：「气泡的点击是不是有问题，为什么会动时间轴」。

查过代码：**跳是有意的**（票 76 的 `openAt`，注释写着「轴只有票 75 那一根，全文面板不另开一条时间轴；
于是牌桌自己就是那一手的快照，两边只有一份渲染」）——这个理由站得住，**别推翻它**。

**漏的是回程**：`RecordOpened None`（关掉面板）只做 `Opened = None`，**游标留在跳过去的那一处**。
于是「读一条理由」变成了「时间轴被搬走」：看完关掉，轴停在别处，再按播放从那儿继续。
上帝视角下四家气泡各指着各自最后一手，点谁都往回跳一段，更晕。

**Blocked by:** None

**Status:** ready-for-agent

## 要什么行为

- [ ] **点开记住原处，关掉回到原处**：关面板（`bubble-close`）之后游标与播放状态回到点开之前那一刻
- [ ] **按「播放」也算关**（今天任何推进牌桌的消息都会收起面板）：那时同样要先回原处再继续播，
      **不许从跳过去的地方接着播**
- [ ] **面板上说出来它跳到哪了**：摊开时明写「正在看第 N 手」（今天只有 `data-bubble-turn` 给机器看，
      人看不见自己被搬到了哪儿）
- [ ] Live 那一侧本来就没有游标（`openAt` 只摆快照、`live.Table` 一字不动），**行为不许变**
- [ ] 「一点就暂停」保留（票 76 的判据：牌桌上摆着快照时定时器推得再快人也看不见）

## 闸门

- [ ] 回放里：记下游标 → 点开某家气泡（断言游标真的挪了、面板真的开了）→ 关掉 →
      **断言游标逐字回到原处**，且播放状态与点开之前相同
- [ ] 同一条路走「按播放」而不是「按关闭」：断言也回到原处再往下播
- [ ] 连点两家气泡再关：断言回到**最初**那一处（不是上一次跳的地方）
- [ ] Live 那一侧：点开 / 关掉前后 `live.Table` 与推进能力（`canAdvance`）逐项不变
- [ ] 每条先红一次，红的原始输出抄进报告

## 边界

- [ ] **不推翻「点开跳到那一手」这条设计**（票 76 的理由仍然成立：一根轴、一份渲染）
- [ ] 不动 `reveals` / `unlocked`（票 81 立的两根轴，M3 的地基）
- [ ] 不动气泡的文字判据与 72 字上限（票 81 刚量出来的）
- [ ] 不碰引擎、`Paifu`、`web/src/agent/**`、`web/public/demo-paifu.json`
- [ ] 不碰牌桌几何与页面块次序（票 82 正在动，**它若已并入就以 `main` 为准**）
- [ ] testId 只许增

## 顺手记着

这条挂账的形状值得记：**票 76 把「跳过去」写进了注释与实现，却没人问「怎么回来」**——
一个动作只做了一半，而两边的用例各自都绿（点开有快照 ✓、关掉面板没了 ✓）。
**闸门要成对地想：状态被改了，就要有一条断言管「改回来」。**
