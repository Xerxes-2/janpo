# 141 — 一屏英文说明，不做全量 i18n

**What to build:** 一页静态英文说明（这是什么 · key 在哪 · 点哪里开始 · 三档脚手架是什么），顶条一个入口。评审 P2-H。

**Status:** ready-for-agent

## 为什么不做全量 i18n

四百条文案 + Fable 侧的改动，代价与收益不成比例。而会为「LLM 打麻将」点进来的人
很大一部分读英文——**一页说明就把这一半人接住了**。

## 要什么行为

- [ ] 一条新路由的静态页（`Route.fs` 加一条），顶条一个入口
- [ ] 内容四段：这是什么 / key 去了哪 / 从哪里开始 / 三档脚手架各是什么。
      **README 那段英文已经写好了，搬过去**——但搬完之后两处就是两份，
      闸门要有一条钉住「key 去了哪」那句在两处说的是同一件事（同票 34 那条对外声称的规矩）
- [ ] 中文那一侧一个字都不改
- [ ] 无头闸门：这一页能打开、四段都在、链接回得去

## 边界

- [ ] **不引 i18n 框架、不动任何既有中文文案**
- [ ] 不动 `web/src/agent/**`、不动引擎
- [ ] 不做语言自动检测（那会让中文用户莫名其妙落到英文页）
