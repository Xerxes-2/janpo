## 要什么行为

- [x] 上家（左）与下家（右）：手牌、河、副露全部**竖向排布，牌面旋转 90°**；对家与自家照旧横排
      —— 上家顺时针 90°、下家逆时针 90°（各自「正着」摆在自己面前）；三排变三列，河仍贴桌心
- [x] 旋转后**语义记号一个不丢**：横放（副露来源，与竖排叠加时尤其要想清楚）、刚摸那张的间隔、
      摸切虚线、立直标签、赤牌、危险度色阶、暗牌牌背
      —— 横放那张在竖排里**正着摆**（与邻牌仍差 90°，且不倒过来）；刚摸那张的间隔改成纵向；
      其余五样与几何无关，闸门逐条仍绿
- [x] 一手牌读得出是一手牌：14 张在竖向不换列 —— 断言化：一列牌 x 相同、y 递增（报告 §3.1 ①'）
- [x] **名牌带选手身份**：
      - Live：那一席引用的**档案名 + 脚手架档位**（bot 席显示「均匀随机」/「有主见」）
