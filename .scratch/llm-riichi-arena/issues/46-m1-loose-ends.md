- [ ] **30-A**：自定义端点的 provider id 叫 `custom`。pi-ai 哪天真有个同名家，会**静默地**让那一家进不来。
      改成 `custom-openai`。**注意迁移**：这个值进过 localStorage 与牌谱的坐席配置——
      旧值读到时要么兼容要么明确报错，**不许静默读成别的东西**
- [ ] **31-D**：人格与模板换了会废缓存，页面上没有任何提示。把**渲染版本**显示出来
      （现在只在牌谱与 `print-prompt` 里看得到），让做对照实验的人当场看得见自己换了渲染
- [ ] **31-C**：`.llm-panel textarea`（人格与模板那两格）没样式，走的浏览器默认。补齐，与面板其余控件归一
- [ ] **37-A**：页脚没有版权年份与作者（README 写的是「MIT © 2026 Xerxes-2」）。补上，与 README 一致
- [ ] **33-A**：`Agent.fs:182` 的注释指向「README 的『渲染层出口』约定」，而那条约定已搬去
      `docs/development.md`。修死链接
- [ ] **36-C**：打码措辞（`[API key 已打码]` / `[端点地址已打码]`）是**产品面的字**，会出现在页面与牌谱里。
      定稿即可（现在就挺好），但**故意写成两份**（`redact.ts` 与 `verify-redaction.mjs`）这件事
      要在两处都留注释说明「改一处必须改另一处」，免得后人以为是重复代码顺手抽掉
