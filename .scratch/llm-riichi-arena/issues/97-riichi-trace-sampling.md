# 97 — 让立直那一族属性真的开口：给 `GameStateArbitraries` 补一条摊好牌山的立直轨迹

**What to build:** 票 96 把 `GameStateArbitraries` 的整个取值域数了一遍：
**217,574 个局面里只有 104 个「有家立直中」（0.103%）**，且全部来自 `riichiSeeking` 那一条轨迹。
换算下来 `RiichiProperties` 那五条断言**一趟只有约 10% 的概率开过口**——
**十趟 CI 有九趟它们是空转的**（判据 3：执行 0 次的断言与不存在等价）。
这一票把采样修到「每趟都开口」，做法照 `kanTrace` 当年给杠做的那样：
往 `tracesFor` 里补**摊好牌山的立直轨迹**（`RiichiTests` 里现成的
`ippatsuTsumoScript` / `minogashiScript` 就够用）。

**Blocked by:** 无（96 已集成；这一票动的是测试取值域，不动引擎）

**Status:** ready-for-human

## 为什么它值一张票

M3 到现在栽在「断言看着在守、其实没执行」上的次数：票 96 那条属性红过一次没人能复现（因为一趟只有 10% 开口）、
票 95 花了半小时自证「不是我」。**采样稀到这个程度的属性，是在替所有人掷骰子。**
而这不是随机属性该有的样子：`kanTrace` 已经证明了「摊好牌山把稀有局面喂进去」这条路走得通。
