# 骨架原型结论（要扔的原型，不进 src/、不接闸门）

跑法：`node .scratch/proto/shoot.mjs` → `shots/*.png` + 数。

## v1 要回答的那一个问题

> 固定舞台 + 四家围中央的标准麻将几何，能不能在 1280×800 落地那一眼装下**终盘**
> （河 16–19、两家立直、四组副露、127 枚牌），且缩放只改大小不改结构。

**答：能。** 舞台 1200×750，`scale = min(vw/1200, vh/750)`，牌桌 656×656、盘心 (328,328)。

| 视口 | scale | 自家牌宽 | 越出牌桌 | 一屏 | 文档滚动 |
|---|---|---|---|---|---|
| 1280×800 | 1.067 | 32 px | 0 | ✓ | 无 |
| 1440×900 | 1.200 | 36 px | 0 | ✓ | 无 |
| 390×844 | 0.325 | **9.8 px** | 0 | ✓ | 无 |

今天的对照：`?table=1` 牌桌顶 810 px（视口 800）＝ 0 px 可见；手机 3.69 屏。

## v2 收的三条（主人第二轮）

1. **照雀魂** —— 雀魂的分法是「点数在中央盘四边、名字/头像在席位边上、宝牌在顶角」。
   照抄：中央盘 180×180 只放 `局/本场/供托/余牌` + 四家「风位·点数」（当前家染朱、親加记号）；
   名字挪到两侧 margin 的四枚名牌，**风位是名牌与中央盘对上的钥匙**；宝牌上顶条。
   ⇒ `deepseek/deepseek-v4-flash` 全名一个字没截（v1 只塞得下 5–11 字）。
2. **气泡可覆盖，但要点得开点得收** —— 收起态 47×28 小气泡（`说 ▾` / `想… ▾`），
   展开态 260×47。四席各走「开 → 收」一个来回，两个方向都真点。
   **覆盖权我留作底牌，没一上来就用**（见下）。
3. **白板描边** —— `.tile.haku { box-shadow: inset 0 0 0 2px var(--indigo) }`，票 80 的账，v1 漏了。
   实测 5 枚全描上。

## 覆盖权怎么用的（要主人确认）

收起态是**常驻**的，让一枚常驻小气泡永久压着一张牌是白占。所以气泡挂在各自名牌
下面——两侧 margin 本来全空，244 px 的展开宽装进 258 px 的可用宽。实测：

- 收起气泡 × 牌 = **0**
- 展开气泡 × 牌 = **0**
- 名牌 × 牌 = 0、名牌 × 气泡 = 0
- 抽屉 × 牌桌 = **没盖**（抽屉收窄到 272 = 右 margin 宽；v1 盖住了下家整列手牌）

若主人要的是「展开就盖住半张牌桌、字更大」的取法，换一版即可——权限在手。

## 闸门的账

主人准许覆盖 ⇒ **撤掉 `verify-bubbles`「气泡不与牌排/中央相交」**。
覆盖率不能凭空消失，提议三条顶上来（都在原型里量过）：

| 撤 | 顶上来 | 实测 |
|---|---|---|
| 气泡不与牌排/中央相交 | ① **收起态** × 牌 = 0（常驻的不许压牌） | 0 ✓ |
| | ② 点得开**且**点得收（四席各一个来回，两个方向都真点） | 4/4 ✓ |
| | ③ 收起态尺寸有上限（是「小气泡」不是卡片） | 47×28 / 60×28 ✓ |

③ 不能省：没有上限，「收起」可以退化成什么都不收，而 ①② 照样绿——判据 60 那个坑。

其余闸门：

| 闸门 | 今天 | 新骨架下 |
|---|---|---|
| `verify-home`「一屏」`board.bottom − ops.top ≤ 800` | 绿（723） | **换成**「舞台 ≤ 视口 且 无文档滚动」 |
| `verify-seats`「四席同屏」 | 绿 | **固定舞台使它恒真 ⇒ 同义反复**（判据 60）。要重新指向「牌不越出牌桌」 |
| `verify-board` computed style（摸切虚线/赤五朱框/牌背/白板描边） | 绿 | 全部可移植，原型里保留了 |
| `@media (max-width: 39.99rem)`（票 44，无闸门） | — | **删**。README「没有为手机屏幕适配」变字面真话 |

## v3 收的两条（主人第三轮）

1. **横牌的图案没横** —— v2 只把**盒子**换成了横的（`width/height` 互换），
   里面的 `<img>` 还竖着，于是牌面被压扁。修：给 img 竖着的尺寸再 `rotate(-90deg)`。
   **立直宣言牌是同一个病**（主人只点了副露，但那枚也一样），一并修了。
2. **两側大片空白** —— 那两片不是「空白」而是「未分配」：原型只搬了牌桌。
   填进去两张本来就得有地方住的卡片：**信息辅助**（右上：向听/有效牌/现物/无筋）
   与**危险度图例**（左下：现物/筋/无筋/宝牌周边，靖蓝・墨・朱红三相分四档，
   没动第五个色相，票 80 的四色相纪律守住）。

### 横牌那条断言写错过一次（要记住）

第一版量的是「img 的屏幕矩形宽 > 高」。拆掉旋转与装回旋转**都报 3 枚**——
一个对错两态同值的断言，彻底无效。原因：席区自身转了 0/90/180/270，
左右两家的横牌在屏幕坐标里**本来就该是竖的**。
改成与席区旋转无关的不变量：**牌面与它自己的盒子同朝向**
（`sign(boxW−boxH) === sign(imgW−imgH)`）。验证：拆旋转 **6/6 全红**，装回 **0**。

## v4 收的一条：把复盘搬进两側

**两列分工**（这就是那两片空白的答案）：

| | 对局中（play） | 终局后（review） |
|---|---|---|
| **左列 = 谁在打** | 名册（四席全名 + 立直记号）+ 危险度图例 | 名册 + **复盘导航**（筛选开关、值得看的那几手、强 AI 分歧数） |
| **右列 = 这一手怎么看** | 信息辅助（向听/有效牌/现物/无筋） | **当手全文**（headline / figures / advice / 强 AI 那一行 / 当时它说的） |

气泡改成从名册点开的**浮层**，浮在牌桌上（主人给的覆盖权用在这儿；
实测展开态×牌 = 6）。收起态就是名册行尾那一个字，**不占牌桌一寸**。

### 硬约束：复盘不能画在对局中那一屏

`ReviewShown` 三态（`Review.fs`）：`Hidden`（未终局 ⇒ **整块不在 DOM 里**，
对局中给「换打会怎样」算作弊）、`Unaddressed`（终局但上帝视角 ⇒ 只说一句
「切到某一席就看得了」）、`Notes`。∴ review 屏必须是「终局 + 坐位视角」，
顶条那枚选中的是「座位 0」而不是「上帝视角」。文案逐句拄 `Review.fs` 的渲染出口，不自造。

### 四个断言写错过，四个都是「静静绣」

这一轮每一次都是先信了数、再看图才发现的：

| 断言 | 怎么假的 | 改法 |
|---|---|---|
| 几何三数全绿（v1） | 舞台被 `transform-origin: 0 0` 顶出视口、名牌压在河上 | 量「牌不越出牌桌」而不是一个合数 |
| 横牌牌面服向（v3） | 拿屏幕坐标量，拆旋转与不拆**都报 3 枚** | 改量「牌面与它自己的盒子同朝向」（与席区旋转无关） |
| 列内溢出（v4） | `display:none` 的卡片矩形全零，`top 0 < 58` 被当成溢出 | 滤掉零尺寸子元素 |
| 名字被截（v4） | 选择器还指着旧名 `.nameplate`，**扇了一个空集**，永远报「无」 | 改 `.roster`，并**同时报扇到几个**（0 就是闸门自己坏了） |

第四条修好后又发现 `scrollWidth` 也探不出来：Chrome 对 flex 子项里被 ellipsis
裁掉的文本不抬它（实测四个名字 `scrollWidth === clientWidth`，而图上明明有省略号）。
改用 canvas 按计算样式量文本真实宽度，**并报出最坏余量**。

### 列宽是最长的真实模型名定的

报出余量之后才看见：`deepseek/deepseek-v4-flash` 需要 159.2px、有 159px
——差 **0.2px**。那不是「放得下」，是**巧合**。拿五个真实长名字量了一遍：

| 名字 | 12px / 列宽 244 | 11px / 列宽 256 |
|---|---|---|
| `deepseek/deepseek-v4-flash` | 余 11.8px | 余 37.0px |
| `anthropic/claude-sonnet-4-5` | 余 10.4px | 余 35.7px |
| `google/gemini-2.5-flash-preview` | **截** | 余 16.6px |
| `openai/gpt-4.1-mini-2025-04-14` | **截** | 余 20.5px |
| `qwen/qwen2.5-72b-instruct` | 余 16.0px | 余 40.9px |

∴ 列宽 256 + 名字 11px。**不能靠去掉 provider 前缀缩字**：票 82 的 nameplate 形状
必须匹配 `/^[^/\s]+\/[^/\s]+$/`，改它要单票授权。

### 浮层一次只开一枚

名册相邻两行只差 26px、而浮层高 ~45px。先让它红一次：同时开相邻两席
实测 **互相压 = 1**。改成一次一枚后 = 0。这同时治信息过载：
四枚同时浮在牌桌上没人读得完。

另：浮层的 top 由 JS 对齐到它那一行名册（写成固定槽位时尾巴差 40–60px 指在空处），
闸门量「尾巴落在它那一行的矩形内」。

## 还剩的未决

1. **手机竖屏 9.8 px 牌**，读不出；转 90° 得 15.6 px（+60%），仍不算能用。
2. **抽屉开着时盖住右侧两席的名牌 + 气泡**（截图 C）。在配桌就不在看牌，倾向接受。
3. 副露在手牌的**右上**而非并排右侧，非标准摆法（小事）。
4. 左列导航列表下方仍有 ~180px 空档，但那是**数据相关**的：
   现在是「只看值得看的那几手」= 9 条；拨到「看全部」= 122 条就满了并开始内部滚动
   （卡片内滚动，不是文档滚动，那条不变量仍守着）。
5. ~~两側四处空档~~ —— v4 已填满（上面那张表）。下面这段留作尺寸的依据：
   方牌桌嵌在 16:10 的框里，两側必然各占 0.3×高 = 272 px（共 45% 的舞台宽）。
   而 272 这个数是**最长的模型名**定的：`deepseek/deepseek-v4-flash` 占 ~210 px。
   缩 margin 就得重新截名字——而不截名字正是主人第二轮要的。
   ∴ 这两列只能用**内容**填，不能用几何消。下一批候选：复盘（当手的全文推理、
   强 AI 基线对比、判断记录）——那本来就得有家，而现在无家。

## 一条自省

v1 第一版三个数全绿（越出 0、相交 0、一屏 true）而**几何是坏的**——舞台被
`transform-origin: 0 0` 顶出视口、名牌压在河上、右边缘与底条被切。数没错，
错在没量在该量的位置。这正是判据 22「假绿比假红更危险」，也是上面 ③ 那条的由来。
